---
title: Function vs. Map
kind: synonyms
areas: [sets]
summary: >
  "Function" and "map" (or "mapping") mean exactly the same thing.
  "Map" is more common when the function preserves some structure or acts on geometric objects, but every statement about functions holds for maps, and vice versa.
terms:
  - function
  - map
examples:
  - example: x_sq_on_reals
    why: >-
      "Function" is the usual word for $f(x) = x^2$, because its inputs and outputs are numbers.
  - example: a_linear_map_t_R2_to_R2
    why: >-
      "Linear map" is more common than "linear function" for $T$, partly because "linear function" also means $x \mapsto m x + b$ in school algebra.
  - example: a_continuous_map_from_a_sphere_to_the_plane
    why: >-
      "Map" is the usual word for a continuous map from a sphere to the plane, because in topology and geometry the inputs and outputs are points of spaces.

## Notes

- For where each word is more common, see [map](/dictionary/definitions/map).
- In category theory, "morphism" generalizes "map" to arrows that need not be functions at all.
