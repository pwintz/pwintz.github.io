summary: >
  Relations, functions, and operators all pair the elements of one set with elements of another.
  A [relation](/dictionary/definitions/relation) between $X$ and $Y$ may relate an element of $X$ to any number of elements of $Y$, including none.
  A [function](/dictionary/definitions/function) from $X$ to $Y$ relates each element of $X$ to exactly one element of $Y$, and an [operator](/dictionary/definitions/operator) is a function whose inputs and outputs are vectors, often functions.

## Notes

- A function $f : X \to Y$ is a relation when $f$ is identified with its [graph](/dictionary/definitions/graph-of-function), the set of pairs $(x, f(x))$ for $x \in X$.
  This is how set theory defines functions; see the graduate definition of [function](/dictionary/definitions/function).
- In elementary arithmetic, "operator" means the symbol for an operation, such as $+$ or $\times$.
  That meaning is not part of this hierarchy; see [operation vs. relation](/dictionary/distinctions/relation-vs-operator).
