summary: >
  An expression has a value. An equation or inequality is a statement that can be true or false.
  An identity is an equation that is true for every value of its variables, and a formula is an equation that gives one quantity in terms of others.
terms:
  - expression
  - equation
  - inequality
  - formula
  - identity_equation
examples:
  - example: 3x_plus_2
    why: >-
      There is nothing to be true or false.
  - example: 3x_plus_2_eq_8
    why: >-
      It is true only for $x = 2$.
  - example: sin_squared_x_plus_cos_squared_x_eq_1
    why: >-
      It is true for every $x$.
  - example: a_eq_pi_r_squared
    why: >-
      It gives the area $A$ in terms of the radius $r$, but it is not true for arbitrary values of $A$ and $r$.
  - example: x_squared_geq_0
    why: >-
      It is true for every real $x$, so it is sometimes called an identity too, but it is not an equation.

## Notes

- Do not say "solve the expression." You can simplify or evaluate an expression, and solve an equation or inequality.
- The symbol $\equiv$ is used for identities, for congruence modulo $n$, and for definitions, so it is worth saying which is meant.
