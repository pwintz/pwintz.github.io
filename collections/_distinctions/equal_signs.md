summary: >
  Mathematical writing combines symbols into pieces that play different grammatical roles.
  An expression has a value.
  An equation or inequality is a statement that can be true or false.
  An identity is an equation that is true for every value of its variables, and a formula is an equation that gives one quantity in terms of others.
terms:
  - expression
  - equation
  - inequality
  - formula
  - identity_equation
examples:
  - example: 3x_plus_2
    why: >-
      $3x + 2$ is an expression.
      It is not an equation, inequality, formula, or identity, because it has no relation sign, so there is nothing to be true or false.
  - example: 3x_plus_2_eq_8
    why: >-
      $3x + 2 = 8$ is an equation because it says that two expressions are equal.
      It is not an identity, because it is true only for $x = 2$.
  - example: sin_squared_x_plus_cos_squared_x_eq_1
    why: >-
      $\sin^2 x + \cos^2 x = 1$ is an equation because it says that two expressions are equal.
      It is an identity because it is true for every $x$.
  - example: a_eq_pi_r_squared
    why: >-
      $A = \pi r^2$ is an equation, and it is a formula because it gives the area $A$ in terms of the radius $r$.
      It is not an identity, because it is not true for arbitrary values of $A$ and $r$.
  - example: x_squared_geq_0
    why: >-
      $x^2 \geq 0$ is an inequality because it compares two expressions with $\geq$.
      It is not an equation, because it has no equal sign, even though it is true for every real $x$.

## Notes

- Do not say "solve the expression."
  You can simplify or evaluate an expression, and solve an equation or inequality.
- The symbol $\equiv$ is used for identities, for congruence modulo $n$, and for definitions, so it is worth saying which is meant.
