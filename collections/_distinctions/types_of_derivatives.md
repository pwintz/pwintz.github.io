summary: >
  An ordinary derivative is for a function of one variable. A partial derivative varies one of several variables while holding the others fixed.
  The differential packages all of the partial derivatives into a single linear map.
terms:
  - ordinary_derivative
  - partial_derivative
  - differential
examples_note: >-
  Each cell is the ___ of the function in that row.
examples:
  - example: t_x_squared
    why: >-
      $f$ has two variables, so it has two partial derivatives, which the differential combines into one linear approximation.
  - example: t_x_squared_on_path
    why: >-
      $g$ is a function of one variable, so it has an ordinary derivative.

## Notes

- "Total derivative" is not listed here because it has two conflicting meanings: the derivative along a path, such as $g^{\prime}(t)$ above, and the differential. See [the meanings of "total derivative"](/distinctions/total-derivative).
