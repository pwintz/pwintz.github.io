title: "Graph: chart vs. graph of a function vs. network"
kind: conflicting
areas: [language, sets]
status: draft
summary: >
  The graph of a function is the set of its input-output pairs.
  A graph in graph theory is a network of vertices and edges.
  In everyday use, a graph is any chart that displays data.
terms:
  - graph_chart
  - graph_of_function
  - graph_network
examples_note: >-
  Is the object shown a graph in the ___ sense?
examples:
  - example: set_x_x_squared_x_in_reals
    why: >-
      $\lbrace (x, x^2) : x \in \reals \rbrace$ is the graph of the function $x \mapsto x^2$.
      It is not a chart, because it is a set of points, not a picture, and it is not a network, because it has no vertices or edges.
  - example: a_drawing_of_y_eq_x_squared_on_coordinate_axes
    why: >-
      The drawing is a chart, and it is a picture of the graph of $x \mapsto x^2$.
      It is not a network, because it has no vertices or edges.
  - example: a_bar_graph_of_monthly_rainfall
    why: >-
      A bar graph is a chart because it displays data.
      It is not the graph of a function, because it is a picture, not a set of points, and it is not a network.
  - example: dots_for_cities_and_lines_for_roads
    why: >-
      The dots and lines form a network, whose vertices are cities and whose edges are roads.
      It is not a chart or the graph of a function, because the positions of the dots do not encode numbers.
