## Avoiding the ambiguity

This dictionary uses "range" for the set of outputs that occur, the [image](/dictionary/definitions/image) $f(X)$ of the whole domain $X$.
"Image" is used for the image $f(A)$ of a set $A$ of inputs, which can be smaller than the range.
For the set where outputs are allowed to land, say "[codomain](/dictionary/definitions/codomain)," not "range."
