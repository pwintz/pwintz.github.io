title: Types of difference
kind: family
areas: [language]
status: draft
summary: >
  A difference is the result of subtraction and can be negative.
  No distance is negative.
  An error compares an approximation with the truth, a change compares the end with the start, and a set difference removes elements.
terms:
  - difference
  - distance
  - error
  - change_delta
  - displacement
  - set_difference
examples:
  - example: 3_minus_7_eq_minus_4
    why: >-
      $3 - 7 = -4$ is a difference because it is the result of a subtraction.
      It is not a distance, because a distance cannot be negative.
  - example: abs_3_minus_7_eq_4
    why: >-
      $\lvert 3 - 7 \rvert = 4$ is the distance between $3$ and $7$ on the number line.
  - example: 9_8_minus_9_81_eq_minus_0_01_for_a_measured_value
    why: >-
      $9.8 - 9.81 = -0.01$ is a difference, and it is the (signed) error of the measurement, because it compares the measured value with the true value.
  - example: a_temperature_that_goes_from_20_to_15_degrees
    why: >-
      The change in temperature is $\Delta T = 15 - 20 = -5$ degrees, the end value minus the start value.
  - example: walking_3_m_east_and_then_3_m_west
    why: >-
      The displacement of the walk is $0$, because the walk ends where it started.
      The distance traveled is $6$ m, not $0$ (the distance between the start and end points is $0$).
  - example: set_1_2_3_minus_set_2_eq_set_1_3
    why: >-
      $\lbrace 1, 2, 3 \rbrace \setminus \lbrace 2 \rbrace$ is a set difference because it removes the elements of $\lbrace 2 \rbrace$ from $\lbrace 1, 2, 3 \rbrace$.
      It is not a difference of numbers, because removing elements is not subtraction.

## Notes

- An _offset_ is a fixed amount added to shift a value or position, such as $b$ in $y = m x + b$.
  A _translation_ (or _shift_) moves every point by the same offset.
- "Difference" is used loosely for many of these, so check whether a technical meaning is defined.
