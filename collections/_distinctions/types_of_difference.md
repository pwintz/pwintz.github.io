summary: >
  A difference is the result of subtraction and can be negative. A distance is never negative.
  An error compares an approximation with the truth, a change compares the end with the start, and a set difference removes elements.
terms:
  - difference
  - distance
  - error
  - change_delta
  - displacement
  - set_difference
examples:
  - example: 3_minus_7_eq_minus_4
    why: >-
      A distance cannot be negative.
  - example: abs_3_minus_7_eq_4
    why: >-
      The distance between $3$ and $7$ on the number line.
  - example: 9_8_minus_9_81_eq_minus_0_01_for_a_measured_value
    why: >-
      The (signed) error of the measurement.
  - example: a_temperature_that_goes_from_20_to_15_degrees
    why: >-
      $\Delta T = 15 - 20 = -5$ degrees.
  - example: walking_3_m_east_and_then_3_m_west
    why: >-
      The displacement is $0$, but the distance traveled is $6$ m. (The distance between the start and end points is $0$.)
  - example: set_1_2_3_minus_set_2_eq_set_1_3
    why: >-
      Sets are not subtracted like numbers. Removing elements is not subtraction.

## Notes

- An _offset_ is a fixed amount added to shift a value or position, such as $b$ in $y = m x + b$. A _translation_ (or _shift_) moves every point by the same offset.
- "Difference" is used loosely for many of these, so check whether a technical meaning is defined.
