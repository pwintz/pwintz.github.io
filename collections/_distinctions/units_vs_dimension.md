## Notes

- An equation is dimensionally consistent if both sides have the same physical dimension. This is independent of the choice of units, and checking it (dimensional analysis) catches many errors.
- Quantities with the same dimension can be added after converting units ($1~\mathrm{m} + 1~\mathrm{ft}$). Quantities with different dimensions cannot be added at all ($1~\mathrm{m} + 1~\mathrm{s}$).
- "Dimension" also means the dimension of a vector space, which is unrelated. See [the meanings of "dimension"](/distinctions/meanings-of-dimension).
