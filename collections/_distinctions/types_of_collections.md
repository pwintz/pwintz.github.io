summary: >
  A set ignores order and repetition. A multiset keeps repetition. A sequence keeps order and repetition.
  "Collection" is informal, and "group" is a technical term for a set with an operation.
terms:
  - collection
  - set
  - sequence
  - multiset
  - group
  - indexed_family
examples:
  - example: set_1_2_2
    why: >-
      As a set, it equals $\lbrace 1, 2 \rbrace$ and has two elements.
  - example: tuple_1_2_2
    why: >-
      A sequence of length three, different from $(2, 1, 2)$ and from $(1, 2)$.
  - example: the_roots_of_x_minus_1_squared_counted_with
    why: >-
      The root $1$ appears twice.
  - example: integers_with_addition
    why: >-
      Addition is associative, $0$ is the identity, and $-n$ is the inverse of $n$.
  - example: naturals_with_addition
    why: >-
      No positive integer has an additive inverse in $\mathbb{N}$.
  - example: the_class_of_all_sets
    why: >-
      Treating it as a set leads to Russell's paradox.
