title: Cardinal vs. ordinal vs. nominal numbers
kind: siblings
areas: [numbers]
status: draft
summary: >
  A number can be used to count (cardinal), to give a position in an order (ordinal), or as a label (nominal).
  For finite sets, cardinals and ordinals look the same, but for infinite sets they differ.
terms:
  - cardinal_number
  - ordinal_number
  - nominal_number
examples:
  - example: the_3_in_3_apples
    why: >-
      The "3" in "3 apples" is a cardinal number because it tells how many apples there are.
      It is not an ordinal number, because it gives no position, and it is not a nominal number, because it is not just a label.
  - example: the_3rd_in_finished_3rd
    why: >-
      The "3rd" in "finished 3rd" is an ordinal number because it tells a position in an order.
      It is not a cardinal number, because it does not count anything, and it is not a nominal number, because its order matters.
  - example: the_23_on_a_jersey
    why: >-
      The "23" on a jersey is a nominal number because it is only a label.
      It is not a cardinal or ordinal number: it counts nothing, and player 23 does not come after player 7.
  - example: omega_plus_1
    why: >-
      $\omega + 1$ is an ordinal number: it comes right after $\omega$ in the order of ordinals.
      It is not a new cardinal number, because a set of order type $\omega + 1$ has the same cardinality, $\aleph_0$, as a set of order type $\omega$.
