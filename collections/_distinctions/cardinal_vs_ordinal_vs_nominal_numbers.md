title: Cardinal vs. ordinal vs. nominal numbers
kind: siblings
areas: [numbers]
status: draft
summary: >
  A number can be used to count (cardinal), to give a position in an order (ordinal), or as a label (nominal).
  For finite sets, cardinals and ordinals look the same, but for infinite sets they differ.
terms:
  - cardinal_number
  - ordinal_number
  - nominal_number
examples:
  - example: the_3_in_3_apples
    why: >-
      It tells how many.
  - example: the_3rd_in_finished_3rd
    why: >-
      It tells position.
  - example: the_23_on_a_jersey
    why: >-
      It is a label. Player 23 is not worth more than player 7.
  - example: omega_plus_1
    why: >-
      It is a different ordinal from $\omega$, but the corresponding sets have the same cardinality, $\aleph_0$.
