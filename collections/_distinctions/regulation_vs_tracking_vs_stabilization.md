summary: >
  A feedback controller is designed to meet a goal, and the goals have different names.
  Stabilization makes an equilibrium asymptotically stable.
  Regulation holds an output at a constant set point despite disturbances.
  Tracking makes an output follow a reference that changes over time.
terms:
  - regulation
  - tracking
  - stabilization
examples:
  - example: balancing_an_inverted_pendulum_upright
    why: >-
      Balancing the pendulum is stabilization because the upright position is an unstable equilibrium that feedback must make asymptotically stable.
      It is regulation because the upright position is a constant set point, and it is not tracking.
  - example: cruise_control_holding_100_km_h_on_hilly_roads
    why: >-
      Holding $100$ km/h is regulation because the set point is constant, and the hills act as disturbances.
      It is not tracking, because the reference does not change.
  - example: a_robot_arm_following_a_moving_conveyor_belt
    why: >-
      Following the conveyor belt is tracking because the reference position changes over time.
      It is not regulation, because there is no constant set point.
  - example: a_spacecraft_following_a_planned_trajectory
    why: >-
      Following a planned trajectory is tracking because the reference is a time-varying path.
      It is not regulation, because there is no constant set point.

## Notes

- Tracking can be posed as stabilization: the goal is to make the origin of the error dynamics, in $e = r - y$, asymptotically stable.
  For a time-varying reference, the error dynamics are time-varying.
- In output regulation theory (Francis and Wonham), "regulation" includes tracking references and rejecting disturbances generated by a known exosystem.
  The internal model principle says the controller must contain a model of that exosystem, such as an integrator for constant references.
