summary: >
  Operators, functionals, and transforms are all functions. Their names signal what the inputs and outputs are:
  operators act on vectors (often functions) and return vectors, functionals return scalars, and transforms change the variable of a function.
terms:
  - function
  - operator
  - functional
  - transform
examples:
  - example: square_on_reals
    why: >-
      Its inputs are numbers, not vectors in a space of functions.
  - example: f_to_f_prime_on_differentiable_functions
    why: >-
      It takes a function and returns a function.
  - example: f_to_f_0
    why: >-
      It takes a function and returns a number.
  - example: the_fourier_transform_f_to_hat_f
    why: >-
      It converts a function of time into a function of frequency.
