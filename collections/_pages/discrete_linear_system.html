A discrete-time linear system is a sequence of states $\vect{x}_0, \vect{x}_1, \vect{x}_2, \ldots$ in which each state is found from the one before it by multiplying by a matrix $A$: $$\vect{x}_{k+1} = A \vect{x}_k.$$ Equivalently, $\vect{x}_k = A^k \vect{x}_0$. Such systems describe populations that move between places, money that grows in accounts, and controllers that run once per clock tick. The plot below shows the states for a $2 \times 2$ matrix $A$. Start $\vect{x}_0$ on one of the dashed eigenvector lines to see what makes eigenvectors special.

Eigenvalues of \(A\)

    Why eigenvectors matter

    Suppose that $\vect{v}$ is an eigenvector of $A$ with eigenvalue $\lambda$, which means that $\vect{v} \neq \vect{0}$ and $$A \vect{v} = \lambda \vect{v}.$$ If $\vect{x}_0 = \vect{v}$, then each step multiplies the state by the number $\lambda$, so $$\vect{x}_k = \lambda^k \vect{v}.$$ The states stay on the line through $\vect{v}$. If $|\lambda| < 1$, then the states shrink toward $\vect{0}$; if $|\lambda| > 1$, then the states grow; if $\lambda < 0$, then the states flip from one side of the origin to the other at each step.

    Suppose that $A$ has two linearly independent eigenvectors $\vect{v}_1$ and $\vect{v}_2$ with eigenvalues $\lambda_1$ and $\lambda_2$. Then every starting state is a linear combination $\vect{x}_0 = c_1 \vect{v}_1 + c_2 \vect{v}_2$. Multiplying by $A$ multiplies each part by its own eigenvalue, so $$\vect{x}_k = c_1 \lambda_1^k \vect{v}_1 + c_2 \lambda_2^k \vect{v}_2.$$ Each part changes on its own, as though the other part were absent. This is why the graph of the eigenvector coefficients above shows simple geometric sequences, while the coordinates in the other graph can rise and then fall. For large $k$, the part with the larger $|\lambda|$ outgrows the other, so $\vect{x}_k$ lines up with its eigenvector, unless its coefficient is $0$. Every state tends to $\vect{0}$ exactly when $|\lambda_1| < 1$ and $|\lambda_2| < 1$.
