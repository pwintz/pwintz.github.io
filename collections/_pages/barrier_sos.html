This page sets up a sum-of-squares (SOS) program whose feasibility proves that no solution of a hybrid system that starts in an initial set reaches an unsafe set. It follows Prajna and Jadbabaie, “Safety Verification of Hybrid Systems Using Barrier Certificates” (HSCC 2004, LNCS 2993), recast in the hybrid inclusion framework of Goebel, Sanfelice, and Teel, Hybrid Dynamical Systems (Princeton, 2012). Describe the system below to get the program as rendered math, LaTeX source, and MATLAB code for SOSTOOLS or YALMIP. Nothing is solved on this page.

Background: barrier certificates for hybrid inclusions

Model

A hybrid system \(\mathcal{H} = (C, F, D, G)\) has flows \(\dot x \in F(x)\) while \(x \in C\) and jumps \(x^+ \in G(x)\) while \(x \in D\). The state is \(x = (z, q)\), where \(z \in \mathbb{R}^n\) is continuous and \(q\) is a logic variable (mode) in a finite set. (With one mode, \(x = z\).) The data are polynomial:

  • In mode \(q\), flows satisfy \(\dot z = f_q(z, w)\) with a disturbance \(w \in W_q\), while \(z \in C_q\). So \(F(z, q) = \{(f_q(z, w), 0) : w \in W_q\}\).
  • Each jump \(j\) goes from mode \(q_j\) to mode \(q_j'\) with \(z^+ = g_j(z, v)\), \(v \in V_j\), while \(z \in D_j\). Several jumps with the same \(D_j\) give a set-valued \(G\).
  • Solutions start in \(X_0\) and must avoid \(X_u\), where \(X_{0,q}\) and \(X_{u,q}\) are the parts in mode \(q\).

Every set is a finite union of basic semialgebraic sets \(\{z : g_i(z) \ge 0,\ h_k(z) = 0\}\).

Sufficient conditions

Suppose that, for some \(\varepsilon > 0\), continuously differentiable \(B_q\), continuous \(\lambda_q\), and \(\sigma_j \ge 0\), the following hold for every mode \(q\) and jump \(j\):

\[ \begin{aligned} B_q(z) &\le 0 && \forall z \in X_{0,q}, \\ B_q(z) &\ge \varepsilon && \forall z \in X_{u,q}, \\ \langle \nabla B_q(z), f_q(z, w) \rangle &\le \lambda_q(z) B_q(z) && \forall (z, w) \in C_q \times W_q, \\ B_{q_j'}(g_j(z, v)) &\le \sigma_j(z, v)\, B_{q_j}(z) && \forall (z, v) \in D_j \times V_j. \end{aligned} \]

Then no solution of \(\mathcal{H}\) starting in \(X_0\) reaches \(X_u\). On each interval of flow, \(b(t) = B_q(z(t))\) is absolutely continuous with \(\dot b \le \lambda_q b\), so by Grönwall’s inequality \(b\) cannot become positive. At a jump from a point with \(B \le 0\), the last condition and \(\sigma_j \ge 0\) give \(B \le 0\) after the jump. By induction over the hybrid time domain, \(B \le 0\) along the whole solution, while \(B \ge \varepsilon\) on \(X_u\).

  • The term \(\lambda_q B_q\) plays the role of Prajna and Jadbabaie’s multiplier \(-\lambda_{B_l}\) in (16), which relaxes “\(\langle \nabla B, f \rangle \le 0\) where \(B = 0\)”. That condition alone is not sufficient. For example, \(\dot z = 1\), \(B(z) = z^3\), \(X_0 = \{z \le -1\}\), and \(X_u = \{z \ge 1\}\) satisfy it, but every solution reaches \(X_u\). The Grönwall form above is sound for any polynomial \(\lambda_q\), of either sign, and it is what their SOS conditions (16) actually impose.
  • In this framework, maximal solutions may end when they can neither flow nor jump, so the conclusion concerns solutions while they stay in \(C \cup D\). A bounded \(C_q\) plays the role of the region \(\mathcal{X}\) in Prajna and Jadbabaie’s Theorem 1.
  • A time-invariant uncertain parameter \(p\) can be a state with \(\dot p = 0\), with its range in \(C\) and \(X_0\), and with no change at jumps. Then \(B\) may depend on \(p\).
  • With an integral constraint \(\int_0^T \phi(z, w)\,dt \ge 0\) (such as an IQC), the flow condition becomes \(\langle \nabla B_q, f_q \rangle + \tau \phi \le 0\) on \(C_q \times W_q\) for some \(\tau \ge 0\), and jumps need \(B_{q_j'} \circ g_j \le B_{q_j}\) (\(\lambda = 0\), \(\sigma = 1\); their Theorem 3).

SOS relaxation

Each condition “\(p \ge 0\) on \(\{g_i \ge 0,\ h_k = 0\}\)” is replaced by \(p - \sum_i s_i g_i - \sum_k \mu_k h_k \in \Sigma\), where \(\Sigma\) is the set of SOS polynomials, \(s_i \in \Sigma\), and \(\mu_k\) are arbitrary polynomials (their Proposition 3). For a union of pieces, there is one SOS constraint per piece. The unknowns enter linearly, so the program is a semidefinite program, if either

  • Synthesize: \(B_q\) is unknown, and \(\lambda_q\) and \(\sigma_j\) are fixed. With \(\lambda_q = 0\), this is their convex Proposition 2.
  • Verify: \(B_q\) is given, and \(\lambda_q\) and \(\sigma_j\) are unknown.

Alternating between the two, while enlarging the disturbance sets, is their Algorithm 1. Each SOS constraint has the smallest even degree that fits its fixed terms, and the multipliers are sized to match. “Extra multiplier degree” adds 2 to all of them.

Numerical tip. With \(\lambda_q = 0\), \(\langle \nabla B_q, f_q \rangle = 0\) at every equilibrium in \(C_q\), so the flow SOS polynomial has a zero there and its Gram matrix can’t be positive definite. Solvers often report inaccurate results then. Excluding equilibria from \(C_q\) (as their Example 2 does) or using \(\lambda_q \ne 0\) avoids this. Always check the solver’s status and accuracy.

Input syntax
  • Polynomials use + - * / ^ (or **) and parentheses, like 2*x1^2 - (x2 + p)/3. Multiplication needs *. You can only divide by constants.
  • Variables are separated by spaces or commas, or give a number, like 3 for x1 x2 x3. Parameters are name = value lines and may use earlier parameters.
  • Sets have one constraint per line, using <=, >=, or =. Chains like 0 <= x1 <= 1 give two constraints, and < is treated as <=. A line saying or starts another piece of a union. empty is the empty set.
  • Flow and jump maps have one box per state variable. A blank jump-map box means that variable doesn’t change.
  • Comments start with # or %.
