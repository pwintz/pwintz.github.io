pricing: InSync requires a one-time purchase <i>for each account you want to sync</i>
alternatives:
  - <a href="/useful-software/git">Git</a> - Requires remembering to manually push changes to a remote repository. Is not designed to store media files or other large binary files. 
  - rclone - As a command line tool, rclone has a more involved setup process than insync, but also is an attractive alternative due to being free and open source.
