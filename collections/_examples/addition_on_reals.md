---
title: 'Addition $+$ on $\reals$'
level: elementary
is: [
  binary_operation,
  associative,
  commutative
]
is_not: [relation]
why:
  binary_operation: >-
    Addition on $\reals$ is a binary operation, because addition combines two real numbers into a new one: "$2 + 4$" produces $6$.
  relation: >-
    Addition on $\reals$ is not a relation, because "$2 + 4$" does not have a true or false value.
  associative: >-
    Addition on $\reals$ is associative: for example, $(2 + 3) + 4 = 2 + (3 + 4) = 9$.
  commutative: >-
    Addition on $\reals$ is commutative: for example, $2 + 3 = 3 + 2 = 5$.
---
