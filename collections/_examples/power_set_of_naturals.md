---
title: 'The set of all subsets of $\nats$'
level: undergraduate
is: [infinite_set, uncountable]
is_not: [finite_set, countable, countably_infinite]
why:
  uncountable: >-
    By Cantor's theorem, no set is in bijection with the set of all of its subsets.
  countable: >-
    The set of all subsets of $\nats$ is not countable, because it is uncountable.
  finite_set: >-
    The set of all subsets of $\nats$ is not finite, because it is uncountable.
---
