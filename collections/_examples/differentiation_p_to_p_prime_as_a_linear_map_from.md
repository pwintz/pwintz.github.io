title: 'Differentiation $p \mapsto p^{\prime}$, as a linear map from polynomials to polynomials'
level: undergraduate
is: [surjective, endomorphism]
is_not: [injective, bijective, automorphism]
why:
  endomorphism: >-
    Differentiation is a linear map from the polynomials to themselves, so it is an endomorphism.
  surjective: >-
    Differentiation $p \mapsto p^{\prime}$ is surjective onto the polynomials, because every polynomial has an antiderivative.
  injective: >-
    Differentiation $p \mapsto p^{\prime}$ is not injective, because every constant maps to $0$, so it is not bijective or an automorphism.
---
