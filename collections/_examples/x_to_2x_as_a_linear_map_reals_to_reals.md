title: '$x \mapsto 2x$, as a linear map $\reals \to \reals$'
level: high-school
is: [
  injective,
  surjective,
  bijective,
  endomorphism,
  automorphism
]
why:
  endomorphism: >-
    $x \mapsto 2x$ is a linear map from $\reals$ to itself, so it is an endomorphism.
  automorphism: >-
    $x \mapsto 2x$, as a linear map $\reals \to \reals$, is bijective, with inverse $x \mapsto x / 2$, so it is injective, surjective, and an automorphism.
