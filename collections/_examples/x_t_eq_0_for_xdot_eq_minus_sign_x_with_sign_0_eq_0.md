title: '$x(t) = 0$, for $\dot{x} = -\operatorname{sign}(x)$ with $\operatorname{sign}(0) = 0$'
level: graduate
is: [classical_solution, caratheodory_solution, filippov_solution, krasovskii_solution, hermes_solution]
why:
  hermes_solution: >-
    $x(t) = 0$ is a Filippov, Krasovskii, and Hermes solution because $0 \in [-1, 1]$, the set-valued regularization of $f$ at $0$.
  caratheodory_solution: >-
    $x(t) = 0$ is a classical solution, and so a Carathéodory solution, because $\dot{x} = 0 = f(0)$ at every $t$.
