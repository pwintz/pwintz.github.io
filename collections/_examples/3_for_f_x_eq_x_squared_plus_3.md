published: false
title: '$3$, for $f(x) = x^2 + 3$'
level: high-school
is: [
  minimum,
  infimum
]
is_not: [minimizer]
why:
  minimum: >-
    $3$ is the minimum value of $f$, and so its infimum, because $f(x) = x^2 + 3 \geq 3$, with equality at $x = 0$.
  minimizer: >-
    $3$, for $f(x) = x^2 + 3$, is not the minimizer, which is the point $0$ where the minimum occurs.
---
