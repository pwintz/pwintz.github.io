title: 'The single data point $5$'
level: high-school
values:
  variance: '$0$'
  sample_variance: 'Undefined ($\frac{0}{0}$)'
why:
  variance: >-
    The variance of the single data point $5$ is $0$, because the data point equals its mean.
  sample_variance: >-
    The sample variance of the single data point $5$ is undefined, because the formula divides $0$ by $1 - 1 = 0$; one measurement says nothing about how spread out the population is.
