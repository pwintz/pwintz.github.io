---
title: '$1/2$'
level: high-school
is: [
  rational_number,
  algebraic_number,
  real_number,
  fraction
]
is_not: [
  integer,
  irrational_number,
  transcendental_number
]
why:
  # integer: >-
  #   $1/2$ is not an integer, and it is not irrational or transcendental.
  rational_number: >-
    $1/2$ is a rational number because it can be written as a ratio of $1$ and $2$.
  algebraic_number: >-
    $1/2$ is algebraic because it is a root of $2x - 1$.
