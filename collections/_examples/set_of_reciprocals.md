title: 'The set $S = \setdef{1/n \suchthat n \geq 1}$'
level: high-school
is: [set]
values:
  limit_point: '$0$'
  minimum: '$\min S$ does not exist'
  maximum: '$\max S = 1$'
  infimum: '$\inf S = 0$'
  supremum: '$\sup S = 1$'
why:
  limit_point: >-
    The only limit point of $S = \setdef{1/n \suchthat n \geq 1}$ is $0$; each point of $S$ is isolated.
    Points of $S$ get arbitrarily close to $0$, though $0 \notin S$.
    Each point of $S$ is isolated; for example, the ball of radius $1/4$ around $1$ contains no other point of $S$.
  minimum: >-
    For every $1/n$ in $S$, $1/(n + 1)$ is smaller.
  supremum: >-
    The maximum of $S$ is $1$, which equals the supremum.
