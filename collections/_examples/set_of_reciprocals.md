title: 'The set $S = \lbrace 1/n : n \geq 1 \rbrace$'
level: high-school
is: [set]
values:
  limit_point: '$0$ (its only limit point)'
why:
  limit_point: >-
    Points of $S$ get arbitrarily close to $0$, though $0 \notin S$. Each point of $S$ is isolated; for example, the ball of radius $1/4$ around $1$ contains no other point of $S$.
