title: 'The statement "$n$ is even," in the argument "$n$ is even; therefore, $n^2$ is even," for an integer $n$'
level: high-school
is: [premise]
is_not: [axiom]
why:
  premise: >-
    The statement "$n$ is even" is a premise of the argument, because the argument starts from "$n$ is even" and concludes that $n^2$ is even.
  axiom: >-
    The statement "$n$ is even" is not an axiom of arithmetic, because "$n$ is even" is assumed only within this argument, and many integers are odd.
