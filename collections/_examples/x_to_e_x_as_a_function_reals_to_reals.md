published: false
title: '$x \mapsto e^x$, as a function $\reals \to \reals$'
level: high-school
is: [injective]
is_not: [
  surjective,
  bijective
]
why:
  injective: >-
    $x \mapsto e^x$ is injective because it is increasing.
  surjective: >-
    $x \mapsto e^x$, as a function $\reals \to \reals$, is not surjective onto $\reals$, because negative numbers are not outputs, so it is not bijective.
---
