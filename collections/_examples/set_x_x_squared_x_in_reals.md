title: '$\setdef{(x, x^2) \suchthat x \in \reals}$'
level: high-school
is: [graph_of_function, curve]
is_not: [function, graph_network, graph_chart]
why:
  function: >-
    $\setdef{(x, x^2) \suchthat x \in \reals}$ is not a function itself, because it is a set of points, not a rule.
  graph_chart: >-
    $\setdef{(x, x^2) \suchthat x \in \reals}$ is the graph of the function $x \mapsto x^2$.
    It is not a chart, because it is a set of points, not a picture, and it is not a network, because it has no vertices or edges.
  graph_of_function: >-
    $\setdef{(x, x^2) \suchthat x \in \reals}$ is the graph of the function $x \mapsto x^2$, and it is a curve (the parabola).
