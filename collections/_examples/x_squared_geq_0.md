published: false
title: '$x^2 \geq 0$'
level: elementary
is: [
  inequality,
  expression_logic
]
is_not: [
  equation,
  expression
]
why:
  equation: >-
    $x^2 \geq 0$ is not an equation, because it has no equal sign, even though it is true for every real $x$.
  expression: >-
    $x^2 \geq 0$ is not an expression in the algebra sense, because it is an inequality: it compares the two expressions $x^2$ and $0$ with $\geq$.
  expression_logic: >-
    $x^2 \geq 0$ is an expression in the logic sense, because $x^2 \geq 0$ is a well-formed string of symbols, namely a formula.
---
