---
title: '$(2, 3) \in \reals^2$'
level: high-school
is: [
  vector,
  point
]
why:
  vector: >-
    $(2, 3)$ is a vector, because $\reals^2$ has a distinguished origin, $(0, 0)$, so each point can be identified with the vector from the origin.
  point: >-
    $(2, 3)$ is a point of $\reals^2$, because it is a location in the plane.
---
