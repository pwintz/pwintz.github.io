---
title: '$\reals$ with the discrete topology'
level: undergraduate
description: >-
  The set of real numbers, with every subset open.
is: [first_countable]
is_not: [
  countable,
  second_countable
]
why:
  countable: >-
    $\reals$ with the discrete topology is not countable, because the [real numbers](/dictionary/examples/reals) are uncountable.
  first_countable: >-
    $\reals$ with the discrete topology is first countable, because, at each point $x$, the single set $\setdef{x}$ is a neighborhood basis.
  second_countable: >-
    $\reals$ with the discrete topology is not second countable.
    Each set $\setdef{x}$ is open, and its only nonempty open subset is itself, so every basis contains $\setdef{x}$ for every real number $x$.
    So every basis has uncountably many sets.
---
