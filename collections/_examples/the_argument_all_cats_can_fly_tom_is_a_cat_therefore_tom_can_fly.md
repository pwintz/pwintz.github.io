title: 'The argument "All cats can fly; Tom is a cat; therefore, Tom can fly"'
level: high-school
is: [
  argument_logic,
  valid_argument
]
is_not: [sound_argument]
why:
  argument_logic: >-
    The cat argument is an argument, with the premises "All cats can fly" and "Tom is a cat" and the conclusion "Tom can fly."
  valid_argument: >-
    The cat argument is valid, because in every situation in which all cats can fly and Tom is a cat, Tom can fly.
  sound_argument: >-
    The cat argument is not sound, because its premise "All cats can fly" is false.
