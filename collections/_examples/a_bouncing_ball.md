---
title: 'A bouncing ball'
level: undergraduate
is: [
  hybrid_system,
  hybrid_automaton
]
is_not: [switched_system]
why:
  switched_system: >-
    A bouncing ball is not a switched system, because the state of the system (its velocity) changes suddenly each time it hits the ground---it does not merely switch into a different mode.
  hybrid_automaton: >-
    The bouncing ball is a hybrid system, and it can be modeled as a hybrid automaton, because it flows between impacts and its velocity jumps at each impact.
---
