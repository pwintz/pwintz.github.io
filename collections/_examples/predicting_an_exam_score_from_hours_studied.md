---
published: false
title: "Predicting a student's exam score, out of $100$, from the number of hours the student studied"
level: high-school
is: [linear_regression]
is_not: [logistic_regression]
why:
  linear_regression: >-
    Predicting an exam score from hours studied is a problem for linear regression, because the score is a number that can be modeled as a linear function of the hours plus an error.
  logistic_regression: >-
    Predicting an exam score from hours studied is not a problem for logistic regression, because the score is a number on a scale, not a yes-or-no outcome.
---
