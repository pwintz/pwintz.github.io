---
title: '$(0, 0) \in \reals^2$, for vector addition'
level: high-school
is: [zero_vector, identity_element]
is_not: [zero_number]
why:
  zero_number: >-
    $(0, 0)$ is not the number zero, because it is a vector.
  identity_element: >-
    $(0, 0)$ is the zero vector of $\reals^2$, and it is the identity element for vector addition, because adding it changes nothing.
---
