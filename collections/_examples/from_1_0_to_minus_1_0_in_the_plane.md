title: 'Turning from $(1, 0)$ to $(-1, 0)$ in the plane'
level: high-school
description: >-
  The vector $(1, 0)$ points east, and the vector $(-1, 0)$ points west.
values:
  angle: '$\theta = 180^\circ$'
  signed_angle: '$\theta = 180^\circ$'
why:
  angle: >-
    The angle between $(1, 0)$ and $(-1, 0)$ is $180^\circ$, because the vectors point in opposite directions.
  signed_angle: >-
    The signed angle from $(1, 0)$ to $(-1, 0)$ is $180^\circ$, because turning either way takes half a turn, and the convention $-180^\circ < \theta \le 180^\circ$ picks $+180^\circ$.
