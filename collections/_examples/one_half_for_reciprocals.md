title: 'The point $1/2$, for the set $\setdef{1/n \suchthat n \geq 1}$'
level: high-school
is: [
  isolated_point,
  adherent_point
]
is_not: [limit_point]
why:
  isolated_point: >-
    The point $1/2$ is an isolated point of $\setdef{1/n \suchthat n \geq 1}$, because the nearest other points of the set are $1/3$ and $1$, so the interval $(1/3, 1)$ meets the set only at $1/2$.
  adherent_point: >-
    The point $1/2$ is an adherent point of $\setdef{1/n \suchthat n \geq 1}$, because $1/2$ belongs to the set.
  limit_point: >-
    The point $1/2$ is not a limit point of $\setdef{1/n \suchthat n \geq 1}$, because no point of the set other than $1/2$ is within $1/6$ of $1/2$.
