---
title: '$1$ and $\setdef{1, 2}$'
level: elementary
is: [element_of]
is_not: [
  subset,
  proper_subset
]
why:
  element_of: >-
    $1$ is an element of $\setdef{1, 2}$ because it is listed in the set.
  subset: >-
    $1$ is not a subset, because it is not a set of elements of $\setdef{1, 2}$.
---
