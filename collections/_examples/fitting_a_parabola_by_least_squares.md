title: 'Fitting a parabola $y = \beta_0 + \beta_1 x + \beta_2 x^2$ to data points by least squares'
level: undergraduate
is: [linear_regression]
why:
  linear_regression: >-
    Fitting a parabola $y = \beta_0 + \beta_1 x + \beta_2 x^2$ by least squares is linear regression, with the features $x$ and $x^2$, because the model is linear in the parameters $\beta_0$, $\beta_1$, $\beta_2$, even though the model is not linear in $x$.
