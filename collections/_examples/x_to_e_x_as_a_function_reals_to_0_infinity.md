title: '$x \mapsto e^x$, as a function $\reals \to (0, \infty)$'
level: high-school
is: [injective, surjective, bijective]
why:
  injective: >-
    $x \mapsto e^x$ is injective because it is increasing.
  surjective: >-
    $x \mapsto e^x$, as a function $\reals \to (0, \infty)$, is surjective, because every positive $y$ is $e^{\ln y}$, so it is bijective.
