published: false
title: 'LQR state feedback $u = -K x$'
level: undergraduate
is: [static_feedback, state_feedback]
is_not: [dynamic_feedback]
why:
  static_feedback: >-
    LQR state feedback is static feedback because the gain $K$ is constant, and the input depends only on the current state.
  dynamic_feedback: >-
    LQR state feedback is not dynamic feedback, because the controller has no state of its own.
---
