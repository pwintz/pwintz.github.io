---
title: 'A precomputed optimal input $u(t)$, applied without measurements'
level: high-school
is: [open_loop]
is_not: [feedback]
why:
  open_loop: >-
    A precomputed input is open-loop control because it uses no measurements.
  feedback: >-
    A precomputed input is not feedback control, so any disturbance or model error goes uncorrected.
---
