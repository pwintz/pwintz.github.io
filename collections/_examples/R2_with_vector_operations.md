---
title: 'The plane $\reals^2$, with vector addition and multiplication by real numbers'
level: undergraduate
is: [
  vector_space,
  module
]
is_not: [algebra_over_a_field]
why:
  vector_space: >-
    The plane $\reals^2$, with vector addition and multiplication by real numbers, is a vector space over $\reals$.
  module: >-
    The plane $\reals^2$, with vector addition and multiplication by real numbers, is a module over $\reals$, because every vector space over a field is a module over that field.
  algebra_over_a_field: >-
    The plane $\reals^2$, with only vector addition and multiplication by real numbers, is not an algebra, because no multiplication of two vectors is given.
---
