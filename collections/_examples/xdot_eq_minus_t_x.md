title: '$\dot{x} = -t x$'
level: high-school
is: [autonomous_no_input, unforced]
is_not: [autonomous_time_invariant, time_invariant]
why:
  unforced: >-
    $\dot{x} = -t x$ is unforced because it has no input.
  time_invariant: >-
    $\dot{x} = -t x$ is not time-invariant, because its right-hand side depends explicitly on $t$.
  autonomous_no_input: >-
    $\dot{x} = -t x$ has no input, so it is autonomous in that sense.
  autonomous_time_invariant: >-
    $\dot{x} = -t x$ is not time-invariant, because its right-hand side depends explicitly on $t$.
