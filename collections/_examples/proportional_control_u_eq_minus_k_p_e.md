title: 'Proportional control $u = -k_p e$'
level: high-school
is: [static_feedback]
is_not: [dynamic_feedback]
why:
  static_feedback: >-
    Proportional control is static feedback because the input depends only on the current error $e$.
  dynamic_feedback: >-
    Proportional control is not dynamic feedback, because the controller has no state.
