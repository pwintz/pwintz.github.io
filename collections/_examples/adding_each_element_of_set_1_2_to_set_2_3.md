title: 'Adding each element of $\setdef{1, 2}$ to each element of $\setdef{2, 3}$ produces $\setdef{3, 4, 5}$'
level: high-school
is: [minkowski_sum]
is_not: [set_union]
why:
  set_union: >-
    Adding each element of one set to each element of the other is not a union, which would give $\setdef{1, 2, 3}$.
  minkowski_sum: >-
    Adding each element of one set to each element of the other is the Minkowski sum: the sums $1 + 2$, $1 + 3$, $2 + 2$, and $2 + 3$ give $\setdef{3, 4, 5}$.
---
