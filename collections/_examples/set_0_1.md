values:
  diameter: '$1$'
  cardinality: '$2$'
  lebesgue_measure: '$0$'
  hausdorff_dimension: '$0$'
why:
  diameter: >-
    The diameter of $\setdef{0, 1}$ is $1$, the distance between its two points.
  cardinality: >-
    The cardinality of $\setdef{0, 1}$ is $2$, because it has $2$ elements.
  lebesgue_measure: >-
    The Lebesgue measure of $\setdef{0, 1}$ is $0$, because each point can be covered by an interval as short as we like.
  hausdorff_dimension: >-
    The Hausdorff dimension of $\setdef{0, 1}$ is $0$, as for every countable set.
