title: '$\setdef{\setdef{1, 2}, \setdef{2, 3}}$, for the set $\setdef{1, 2, 3}$'
level: elementary
is_not: [set_partition]
why:
  set_partition: >-
    $\setdef{\setdef{1, 2}, \setdef{2, 3}}$ is not a partition of $\setdef{1, 2, 3}$, because its blocks overlap at $2$, so it is a cover.
