title: 'The origin, for $\dot{x} = -x$'
level: undergraduate
is: [attractor, attractive, omega_limit_set]
is_not: [limit_cycle]
why:
  attractive: >-
    The origin is attractive and an attractor because every solution of $\dot{x} = -x$ converges to it.
  limit_cycle: >-
    The origin, for $\dot{x} = -x$, is the ω-limit set of every point, and it is not a limit cycle, because it is a single point, not a periodic orbit.
