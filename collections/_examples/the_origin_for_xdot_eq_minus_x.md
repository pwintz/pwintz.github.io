published: false
title: 'The origin, for $\dot{x} = -x$'
level: undergraduate
is: [attractor, attractive, omega_limit_set]
is_not: [limit_cycle]
why:
  attractive: >-
    The origin is attractive and an attractor because every solution of $\dot{x} = -x$ converges to it.
  limit_cycle: >-
    The origin is not a limit cycle of $\dot{x} = -x$, because it is a single point, not a periodic orbit.
  omega_limit_set: >-
    The origin is the ω-limit set of every point for $\dot{x} = -x$, because every solution converges to it.
---
