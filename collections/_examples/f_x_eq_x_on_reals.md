---
title: 'The function $f : \reals \to \reals$ defined by $f(x) = x$'
level: high-school
is: [
  identity_function,
  inclusion_map
]
why:
  identity_function: >-
    The function $f : \reals \to \reals$ defined by $f(x) = x$ is the identity function on $\reals$, because $f$ sends each real number to itself, and its domain and codomain are both $\reals$.
  inclusion_map: >-
    The function $f : \reals \to \reals$ defined by $f(x) = x$ is the inclusion map of $\reals$ into itself, because $\reals$ is a subset of $\reals$ and $f$ sends each real number to itself.
---
