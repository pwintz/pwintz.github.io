title: 'The number $X$ shown by a rolled die'
level: high-school
is: [random_variable]
is_not: [event]
why:
  random_variable: >-
    The number shown by a rolled die is a random variable, because it assigns a number, $1$ through $6$, to each outcome.
  event: >-
    The number shown by a rolled die is not an event, because it is a number for each outcome, not a set of outcomes.
---
