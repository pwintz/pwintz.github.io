---
title: 'The function $\iota : \mathbb{Z} \to \reals$ defined by $\iota(n) = n$'
level: high-school
is: [inclusion_map]
is_not: [identity_function]
why:
  inclusion_map: >-
    The function $\iota : \mathbb{Z} \to \reals$ defined by $\iota(n) = n$ is the inclusion map of $\mathbb{Z}$ into $\reals$, because $\iota$ sends each integer to itself, as a real number.
  identity_function: >-
    The function $\iota : \mathbb{Z} \to \reals$ defined by $\iota(n) = n$ is not an identity function, because its codomain $\reals$ is different from its domain $\mathbb{Z}$.
    For example, no integer is sent to $1/2$.
---
