published: false
title: '$3 : 2$ boys to girls'
level: elementary
is: [ratio]
is_not: [fraction]
why:
  ratio: >-
    $3 : 2$ is a ratio comparing the number of boys with the number of girls.
  fraction: >-
    $3 : 2$ is not a fraction of the class: the fraction of the class that is boys is $\frac{3}{5}$, not $\frac{3}{2}$.
---
