---
title: 'The probability that a uniform random number on $[0, 1]$ is rational'
level: high-school
is: [probability_zero]
why:
  probability_zero: >-
    The event that a uniform random number on $[0, 1]$ is rational has probability zero, because $\mathbb{Q} \cap [0, 1]$ has measure zero. The event is not impossible, however, because every rational number in $[0, 1]$ is a possible outcome.
