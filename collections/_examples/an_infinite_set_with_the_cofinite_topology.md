title: 'An infinite set with the cofinite topology'
level: graduate
is: [T1_space]
is_not: [
  hausdorff_space,
  normal_space,
  metrizable
]
why:
  metrizable: >-
    An infinite set with the cofinite topology is not metrizable, because it is not Hausdorff, and every metric space is Hausdorff.
  T1_space: >-
    An infinite set with the cofinite topology is T₁, because each point is closed.
  hausdorff_space: >-
    An infinite set with the cofinite topology is not Hausdorff, because every two nonempty open sets intersect: each leaves out only finitely many points of an infinite set.
  normal_space: >-
    An infinite set with the cofinite topology is not normal, because two distinct points are disjoint closed sets, and every two nonempty open sets intersect.
---
