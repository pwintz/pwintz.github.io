title: 'An infinite set with the cofinite topology'
level: graduate
is: [T1_space]
is_not: [
  hausdorff_space,
  normal_space,
  metrizable
]
why:
  metrizable: >-
    An infinite set with the cofinite topology is not Hausdorff, and so not normal or metrizable, because every two nonempty open sets intersect.
  T1_space: >-
    An infinite set with the cofinite topology is T₁, because each point is closed.
---
