---
title: '$f \mapsto f^{\prime}$, on differentiable functions'
level: high-school
is: [
  function,
  operator
]
is_not: [functional]
why:
  function: >-
    $f \mapsto f^{\prime}$ is a function, because it assigns one function to each differentiable function.
  functional: >-
    $f \mapsto f^{\prime}$, on differentiable functions, is not a functional, because its outputs are functions, not numbers.
  operator: >-
    $f \mapsto f^{\prime}$ is an operator, because it takes a function and returns a function.
---
