title: '$\dot x_1 = x_2$, $\dot x_2 = u$, with velocity output $y = x_2$'
level: undergraduate
is_not: [observable, reconstructible, detectable]
why:
  detectable: >-
    The double integrator with velocity output is not detectable, because the position's mode (with eigenvalue $0$) does not decay.
  reconstructible: >-
    The double integrator with velocity output is not reconstructible, because the output does not show the position $x_1$.
  observable: >-
    The double integrator with velocity output is not observable, because the output does not show the position $x_1$.
