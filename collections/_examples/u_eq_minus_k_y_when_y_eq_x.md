title: '$u = -K y$, when $y = x$'
level: high-school
is: [state_feedback, output_feedback]
why:
  output_feedback: >-
    $u = -K y$ is output feedback, because the input is computed from the measured output $y$.
  state_feedback: >-
    $u = -K y$ is also state feedback, because here the output is the whole state.
