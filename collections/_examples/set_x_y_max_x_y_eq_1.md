title: '$\setdef{(x, y) \suchthat \max(\abs{x}, \abs{y}) = 1}$'
level: undergraduate
is: [
  sphere,
  sphere_topological
]
is_not: [circle]
why:
  sphere: >-
    The square $\setdef{(x, y) \suchthat \max(\abs{x}, \abs{y}) = 1}$ is the unit sphere for the max-norm distance, so it is a sphere in that metric space, and so a topological sphere.
  circle: >-
    The square $\setdef{(x, y) \suchthat \max(\abs{x}, \abs{y}) = 1}$ is not a circle, because its points are not all at the same Euclidean distance from the origin.
---
