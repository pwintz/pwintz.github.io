---
title: 'Euclid''s parallel postulate'
detail: 'Through a point not on a line, there is exactly one line parallel to the given line.'
level: high-school
is: [
  postulate,
  axiom
]
is_not: [assumption]
why:
  assumption: >-
    Euclid's parallel postulate is not an assumption of a single result; dropping it gives non-Euclidean geometries.
  postulate: >-
    Euclid's parallel postulate is a postulate, and so an axiom, because Euclidean geometry takes it as given without proof.
---
