---
title: 'Euclid''s parallel postulate'
detail: 'Through a point not on a line, there is exactly one line parallel to the given line.'
level: high-school
is: [
  postulate,
  axiom
]
is_not: [assumption]
why:
  assumption: >-
    Euclids parallel postulate is not an assumption, because it is a starting statement of a whole theory, not a hypothesis of a single result. Dropping it gives non-Euclidean geometries.
  postulate: >-
    Euclids parallel postulate is a postulate, because Euclidean geometry takes it as given without proof.
  axiom: >-
    Euclids parallel postulate is an axiom, because it is one of the starting statements of Euclidean geometry, taken as true without proof.
---
