---
title: 'A toaster that runs for a fixed time'
level: elementary
is: [open_loop]
is_not: [closed_loop, feedback]
why:
  open_loop: >-
    A toaster that runs for a fixed time is open-loop control because it does not measure how brown the toast is.
  feedback: >-
    A toaster that runs for a fixed time is not closed-loop or feedback control, because it does not measure how brown the toast is.
---
