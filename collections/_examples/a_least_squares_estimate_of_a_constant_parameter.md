---
title: 'A least-squares estimate of a constant parameter from data'
level: high-school
is: [estimator]
is_not: [
  observer,
  filter_estimation,
  predictor
]
why:
  estimator: >-
    A least-squares estimate is an estimator because it estimates a quantity from data.
  predictor: >-
    A least-squares estimate of a constant parameter from data is not predictor, because it estimates a constant parameter, not a changing state.
  observer: >-
    A least-squares estimate of a constant parameter from data is not an observer, because it estimates a constant parameter, not a changing state.
  filter_estimation: >-
    A least-squares estimate of a constant parameter from data is not filter, because it estimates a constant parameter, not a changing state.
---
