title: '$\setdef{(x, y) \in \reals^2 \suchthat x < y}$'
level: high-school
is: [relation]
is_not: [
  predicate,
  proposition
]
why:
  predicate: >-
    $\setdef{(x, y) \in \reals^2 \suchthat x < y}$ is not a predicate, because it is a set of pairs, not a statement with variables. It is the set of pairs for which the predicate "$x < y$" is true.
  proposition: >-
    $\setdef{(x, y) \in \reals^2 \suchthat x < y}$ is not a proposition, because it is a set, not a statement.
  relation: >-
    $\setdef{(x, y) \in \reals^2 \suchthat x < y}$ is a relation on $\reals$, because it is a subset of $\reals \times \reals$.
---
