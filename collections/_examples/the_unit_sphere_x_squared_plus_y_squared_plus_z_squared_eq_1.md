---
title: 'The unit sphere in $\reals^3$'
level: high-school
detail: |-
  The unit sphere is the set of points $(x, y, z)$ in $\reals^3$ such that

  $$x^2 + y^2 + z^2 = 1.$$
is: [
  sphere,
  connected,
  path_connected,
  simply_connected,
  manifold
]
is_not: [
  ball
]
values:
  dimension_manifold: '$2$'
why:
  sphere: >-
    The unit sphere $x^2 + y^2 + z^2 = 1$ is a sphere, because it consists of the points of $\reals^3$ at distance $1$ from the origin.
  connected: >-
    The unit sphere $x^2 + y^2 + z^2 = 1$ is connected, because it is path-connected, and every path-connected set is connected.
  path_connected: >-
    The unit sphere $x^2 + y^2 + z^2 = 1$ is path-connected, because every two points on it are joined by an arc of a great circle.
  simply_connected: >-
    The unit sphere $x^2 + y^2 + z^2 = 1$ is simply connected, because, although it is hollow, every loop on it can slide along the sphere to a point.
  manifold: >-
    The unit sphere $x^2 + y^2 + z^2 = 1$ is a manifold, because each point has a neighborhood on the sphere that is homeomorphic to an open disk in $\reals^2$.
  dimension_manifold: >-
    The dimension of the unit sphere $x^2 + y^2 + z^2 = 1$ as a manifold is $2$, because the latitude and longitude are coordinates on each small patch of the sphere.
  ball: >-
    The unit sphere $x^2 + y^2 + z^2 = 1$ is not a ball, because it does not include the points inside it, such as the origin.
---
