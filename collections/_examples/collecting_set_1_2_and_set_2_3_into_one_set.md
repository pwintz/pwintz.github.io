published: false
title: 'Collecting the elements of $\setdef{1, 2}$ and $\setdef{2, 3}$ into one set produces $\setdef{1, 2, 3}$'
level: high-school
is: [set_union]
is_not: [
  concatenate,
  minkowski_sum
]
why:
  set_union: >-
    Collecting the elements into one set is a union, so the shared element $2$ appears once.
  minkowski_sum: >-
    Collecting the elements into one set is not concatenation, which keeps order and repeats, and it is not a Minkowski sum, which adds elements together.
---
