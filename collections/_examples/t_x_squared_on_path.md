title: '$f(t, x) = t x^2$ along the path $x(t) = e^t$'
level: high-school
description: >-
  The one-variable function $g(t) = f(t, e^t) = t e^{2t}$.
values:
  ordinary_derivative: '$g^{\prime}(t) = e^{2t} + 2 t e^{2t}$'
  total_derivative: '$\frac{\mathrm{d}}{\mathrm{d}t} f(t, e^t) = e^{2t} + 2 t e^{2t}$'
why:
  total_derivative: >-
    By the chain rule, it equals $\frac{\partial f}{\partial t} + \frac{\partial f}{\partial x} \dot{x}$.
