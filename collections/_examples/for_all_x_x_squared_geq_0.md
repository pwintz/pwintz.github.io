title: '$\forall x \, (x^2 \geq 0)$, with $x$ ranging over $\reals$'
level: undergraduate
is: [sentence_logic, proposition]
is_not: [predicate, expression]
why:
  sentence_logic: >-
    $\forall x \, (x^2 \geq 0)$ is a sentence, because the quantifier binds its only variable $x$.
  proposition: >-
    With $x$ ranging over $\reals$, $\forall x \, (x^2 \geq 0)$ is a proposition, because it is true.
  predicate: >-
    $\forall x \, (x^2 \geq 0)$ is not a predicate, because it has no free variables.
  expression: >-
    $\forall x \, (x^2 \geq 0)$ is not an expression, because it is a statement, not a name for an object.
