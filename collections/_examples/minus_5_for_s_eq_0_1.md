title: '$-5$, for $S = (0, 1]$'
level: high-school
is: [lower_bound]
is_not: [infimum, minimum]
why:
  lower_bound: >-
    $-5$ is a lower bound of $S$ because it is below every element of $S$.
  minimum: >-
    $-5$, for $S = (0, 1]$, is not the infimum, because $0$ is a greater lower bound, and it is not the minimum, because $-5 \notin S$.
