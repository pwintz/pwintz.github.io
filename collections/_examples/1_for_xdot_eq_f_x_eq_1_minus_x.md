---
title: '$1$, for $\dot{x} = f(x) = 1 - x$'
level: high-school
is: [equilibrium, steady_state]
is_not: [fixed_point]
why:
  fixed_point: >-
    $1$ is not a fixed point of $f$, because $f(1) = 0 \neq 1$.
  steady_state: >-
    $1$ is an equilibrium because $f(1) = 0$, and it is the steady state because every solution settles there.
---
