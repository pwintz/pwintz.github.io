published: false
title: '$\dot x_1 = -x_1$, $\dot x_2 = x_2 + u$'
level: undergraduate
is: [stabilizable]
is_not: [controllable, reachable]
why:
  controllable: >-
    The system $\dot x_1 = -x_1$, $\dot x_2 = x_2 + u$ is not controllable, because the input cannot affect $x_1$.
  stabilizable: >-
    The system $\dot x_1 = -x_1$, $\dot x_2 = x_2 + u$ is stabilizable, because $x_1$ decays on its own, and $u = -2 x_2$ stabilizes $x_2$.
  reachable: >-
    The system $\dot x_1 = -x_1$, $\dot x_2 = x_2 + u$ is not reachable, because the input cannot affect $x_1$.
---
