title: 'An observer-based controller'
level: undergraduate
is: [dynamic_feedback]
is_not: [static_feedback]
why:
  dynamic_feedback: >-
    An observer-based controller is dynamic feedback because the observer state $\hat{x}$ is the controller's state.
  static_feedback: >-
    An observer-based controller is not static feedback, because the input depends on the history of the measurements through $\hat{x}$.
---
