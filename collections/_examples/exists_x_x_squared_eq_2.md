---
title: '$\exists x \, (x^2 = 2)$'
level: undergraduate
is: [sentence_logic, formula_logic]
values:
  proposition: 'True if $x$ ranges over $\reals$; false if $x$ ranges over the rational numbers'
why:
  sentence_logic: >-
    $\exists x \, (x^2 = 2)$ is a sentence, because the quantifier $\exists x$ binds the only variable $x$.
  proposition: >-
    $\exists x \, (x^2 = 2)$ expresses a proposition only once the set that $x$ ranges over is chosen: over $\reals$, the number $\sqrt{2}$ satisfies $x^2 = 2$, and over the rational numbers, no number does.
  formula_logic: >-
    $\exists x \, (x^2 = 2)$ is a formula, because $\exists x \, (x^2 = 2)$ applies the quantifier $\exists x$ to the formula $x^2 = 2$.
---
