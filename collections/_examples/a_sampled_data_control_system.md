---
title: 'A sampled-data control system'
level: undergraduate
is: [hybrid_system]
is_not: [switched_system]
why:
  hybrid_system: >-
    A sampled-data control system is a hybrid system because a timer triggers a jump in the held input at each sampling time.
  switched_system: >-
    A sampled-data control system is not a switched system, because the held input jumps, so its state is not continuous.
---
