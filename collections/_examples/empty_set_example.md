---
title: 'The empty set $\emptyset$'
definition: empty_set
level: high-school
is: [open_set, closed_set, finite_set, countable, empty_set]
is_not: [countably_infinite, uncountable]
why:
  open_set: >-
    The empty set is open in $\reals$, because it has no points, so the condition on its points holds vacuously.
  closed_set: >-
    The empty set is closed in $\reals$, because its complement, $\reals$, is open.
  finite_set: >-
    The empty set is finite, because it has $0$ elements, and $0$ is a finite number.
  uncountable: >-
    The empty set is not uncountable, because it is finite.
  countable: >-
    The empty set is countable, because it is finite.
---
