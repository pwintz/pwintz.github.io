title: '$i$, for the function $f : \reals \to \reals$ given by $f(x) = x^2 + 1$'
level: high-school
description: >-
  The imaginary unit $i$ is the complex number such that $i^2 = -1$.
is_not: [zero_of_function]
why:
  zero_of_function: >-
    $i$ is not a zero of $f$, because $i$ is not in the domain $\reals$ of $f$, so $f(i)$ is undefined.
    The function $f$ has no zeros, because $x^2 + 1 \geq 1$ for every real number $x$.
