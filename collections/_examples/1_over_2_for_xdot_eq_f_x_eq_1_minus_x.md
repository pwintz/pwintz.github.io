title: '$\frac{1}{2}$, for $\dot{x} = f(x) = 1 - x$'
level: high-school
is: [fixed_point]
is_not: [equilibrium, steady_state]
why:
  fixed_point: >-
    $\frac{1}{2}$ is a fixed point of $f$ because $f(\frac{1}{2}) = \frac{1}{2}$.
  steady_state: >-
    $\frac{1}{2}$, for $\dot{x} = f(x) = 1 - x$, is not a steady state, because $\dot{x} = \frac{1}{2}$ there, so the state does not stay.
  equilibrium: >-
    $\frac{1}{2}$, for $\dot{x} = f(x) = 1 - x$, is not an equilibrium, because $\dot{x} = \frac{1}{2}$ there, so the state does not stay.
