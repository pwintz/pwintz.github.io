title: '$\dot{x} = -x$, $y = 0$'
level: undergraduate
is: [detectable]
is_not: [observable, reconstructible]
why:
  detectable: >-
    $\dot{x} = -x$, $y = 0$ is detectable, because the unknown state decays to $0$ anyway.
  reconstructible: >-
    $\dot{x} = -x$, $y = 0$ is not observable or reconstructible, because the output carries no information.
