---
title: '$9.8 - 9.81 = -0.01$, for a measured value $9.8$ and true value $9.81$'
level: elementary
is: [
  error,
  difference
]
why:
  difference: >-
    $9.8 - 9.81 = -0.01$ is a difference, because it is the result of a subtraction.
  error: >-
    $9.8 - 9.81 = -0.01$ is the (signed) error of the measurement, because it compares the measured value $9.8$ with the true value $9.81$.
---
