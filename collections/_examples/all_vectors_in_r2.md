title: 'The set of all vectors in $\reals^2$'
level: high-school
is: [spanning_set]
is_not: [
  vector_basis,
  linearly_independent
]
why:
  spanning_set: >-
    The set of all vectors in $\reals^2$ spans $\reals^2$, because every vector in $\reals^2$ is in the set.
  vector_basis: >-
    The set of all vectors in $\reals^2$ is not a basis of $\reals^2$, because the set is not linearly independent.
  linearly_independent: >-
    The set of all vectors in $\reals^2$ is not linearly independent, because $(2, 0)$ is a linear combination of another vector in the set: $(2, 0) = 2 (1, 0)$.
---
