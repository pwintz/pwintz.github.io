---
title: '$\dot{x} = x + 0 \cdot u$'
level: high-school
is_not: [
  controllable,
  reachable,
  stabilizable
]
why:
  stabilizable: >-
    $\dot{x} = x + 0 \cdot u$ is not stabilizable because the state grows exponentially regardless of the input.
  controllable: >-
    $\dot{x} = x + 0 \cdot u$ is not controllable because the input has no effect.
  reachable: >-
    $\dot{x} = x + 0 \cdot u$ is not a reachable system because the input has no effect.
---
