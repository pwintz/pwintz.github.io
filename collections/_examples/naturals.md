---
title: '$\nats$'
details: The set of natural numbers.
level: high-school
is: [infinite_set, countably_infinite, countable]
is_not: [finite_set, bounded, compact, uncountable]
why:
  infinite_set: >-
    $n \mapsto 2n$ is a bijection from $\nats$ onto the even numbers, a proper subset.
  countable: >-
    $\nats$ is countable because the list $0, 1, 2, \dots$ reaches every natural number.
  finite_set: >-
    $\nats$ is not finite, because the list does not end.
  bounded: >-
    $\nats$ is not bounded, because for every $N > 0$, we can pick $n \in \nats$ such that $n > N$.
  compact: >-
    $\nats$ is not finite or compact.
  countably_infinite: >-
    $\nats$ is countably infinite, and so infinite, because it can be listed as $0, 1, 2, \dots$.
  # uncountable: >-
  #   $\nats$ is not bounded, because it has arbitrarily large elements, and it is not uncountable.
---
