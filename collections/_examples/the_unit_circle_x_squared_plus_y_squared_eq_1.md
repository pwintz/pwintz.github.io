---
published: false
title: 'The unit circle $x^2 + y^2 = 1$'
level: high-school
is: [
  curve,
  circle,
  connected,
  path_connected
]
is_not: [
  graph_of_function,
  function,
  simply_connected
]
why:
  simply_connected: >-
    The circle itself is a loop that cannot be shrunk to a point within the circle.
  curve: >-
    The unit circle is a curve.
  path_connected: >-
    The unit circle is path-connected, and so connected, because every two points are joined by an arc of the circle.
  graph_of_function: >-
    The unit circle $x^2 + y^2 = 1$ is not the graph of a function of $x$, because it fails the vertical line test.
  function: >-
    The unit circle $x^2 + y^2 = 1$ is not a function, because it is a set of points, not a rule.
---
