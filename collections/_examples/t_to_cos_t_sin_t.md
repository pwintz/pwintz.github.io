title: '$t \mapsto (\cos t, \sin t)$'
level: high-school
is: [function, curve]
is_not: [graph_of_function]
why:
  graph_of_function: >-
    $t \mapsto (\cos t, \sin t)$ is not a graph of a function, because it is a rule, not a set of points.
  function: >-
    $t \mapsto (\cos t, \sin t)$ is a function from $\reals$ into the plane, because it assigns one point to each $t$.
  curve: >-
    $t \mapsto (\cos t, \sin t)$ is a curve, because it is a parametrized path, whose image is the unit circle.
