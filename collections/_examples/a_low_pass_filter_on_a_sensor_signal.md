---
title: 'A low-pass filter on a sensor signal'
level: high-school
is_not: [observer, filter_estimation, predictor]
why:
  filter_estimation: >-
    A low-pass filter is a filter in the signal-processing sense: it smooths a signal.
  predictor: >-
    A low-pass filter on a sensor signal is not a filter in the estimation sense, an observer, or a predictor, because it does not estimate a state.
