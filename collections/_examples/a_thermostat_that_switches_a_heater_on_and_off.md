---
title: 'A thermostat that switches a heater on and off'
level: high-school
is: [
  hybrid_system,
  hybrid_automaton,
  switched_system
]
why:
  switched_system: >-
    The thermostat is a switched system because the heater mode switches while the temperature changes continuously.
  hybrid_automaton: >-
    A thermostat that switches a heater on and off is a hybrid system, because its heater mode jumps while the temperature flows, and it can be modeled as a hybrid automaton with one mode for "on" and one for "off".
---
