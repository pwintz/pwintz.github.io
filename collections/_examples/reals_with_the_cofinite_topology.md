---
title: '$\reals$ with the cofinite topology'
level: graduate
description: >-
  The set of real numbers $\reals$, where a set is open if it is empty or its [complement](/dictionary/definitions/complement_of_set) is finite.
is_not: [
  countable,
  first_countable,
  second_countable
]
why:
  countable: >-
    $\reals$ with the cofinite topology is not countable, because its points are the real numbers.
  first_countable: >-
    $\reals$ with the cofinite topology is not first countable.
    Suppose that $N_1, N_2, \dots$ are neighborhoods of a point $x$.
    The complement of each $N_k$ is finite, so the union of the complements is countable, and there is a point $y \neq x$ in every $N_k$.
    Then $\reals \setdiff \setdef{y}$ is a neighborhood of $x$ that contains none of the sets $N_k$.
  second_countable: >-
    $\reals$ with the cofinite topology is not second countable, because it is not first countable.
---
