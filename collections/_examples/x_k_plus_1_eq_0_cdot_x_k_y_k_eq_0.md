title: '$x_{k+1} = 0 \cdot x_k$, $y_k = 0$'
level: undergraduate
is: [
  reconstructible,
  detectable
]
is_not: [observable]
why:
  observable: >-
    $x_{k+1} = 0 \cdot x_k$, $y_k = 0$ is not observable, because the output carries no information about the initial state.
  reconstructible: >-
    $x_{k+1} = 0 \cdot x_k$, $y_k = 0$, is reconstructible and detectable, because the state is $0$ after one step, so the current state is known.
---
