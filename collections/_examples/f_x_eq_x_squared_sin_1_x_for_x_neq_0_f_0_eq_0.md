title: '$f(x) = x^2 \sin(1/x)$ for $x \neq 0$, $f(0) = 0$'
level: undergraduate
is: [differentiable]
is_not: [continuously_differentiable, smooth, analytic]
why:
  continuously_differentiable: >-
    $f(x) = x^2 \sin(1/x)$ for $x \neq 0$, $f(0) = 0$, is not continuously differentiable, smooth, or analytic, because $f^{\prime}(x) = 2x \sin(1/x) - \cos(1/x)$ has no limit as $x \to 0$.
  differentiable: >-
    The function $f(x) = x^2 \sin(1/x)$, with $f(0) = 0$, is differentiable, with $f^{\prime}(0) = 0$.
