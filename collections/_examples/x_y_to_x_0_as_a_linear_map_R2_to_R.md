title: '$(x, y) \mapsto (x, 0)$, as a linear map $\reals^2 \to \reals^2$'
level: undergraduate
is: [endomorphism]
is_not: [
  injective,
  surjective,
  bijective,
  automorphism
]
why:
  endomorphism: >-
    The projection $(x, y) \mapsto (x, 0)$ is a linear map from $\reals^2$ to itself, so it is an endomorphism.
  automorphism: >-
    The projection $(x, y) \mapsto (x, 0)$ is not an automorphism, because it is not bijective.
  injective: >-
    The projection $(x, y) \mapsto (x, 0)$ is not injective, because $(0, 1)$ maps to $(0, 0)$.
  surjective: >-
    The projection $(x, y) \mapsto (x, 0)$ is not surjective, because $(0, 1)$ is not an output.
  bijective: >-
    The projection $(x, y) \mapsto (x, 0)$ is not bijective, because it is not injective.
