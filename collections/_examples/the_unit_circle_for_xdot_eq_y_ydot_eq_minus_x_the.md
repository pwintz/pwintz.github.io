title: 'The unit circle, for $\dot{x} = y$, $\dot{y} = -x$ (the harmonic oscillator)'
level: undergraduate
is: [omega_limit_set]
is_not: [limit_cycle, attractive, attractor]
why:
  omega_limit_set: >-
    The unit circle is the ω-limit set of each of its own points, because the solutions on it go around it periodically.
  limit_cycle: >-
    The unit circle, for $\dot{x} = y$, $\dot{y} = -x$ (the harmonic oscillator), is not a limit cycle, because every nearby circle is also a periodic orbit, so it is not isolated, and it is not attractive or an attractor, because nearby solutions do not approach it.
