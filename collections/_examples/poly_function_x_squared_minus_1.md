---
title: '$f(x) = x^2 - 1$, for $x \in \reals$'
level: high-school
is: [
  polynomial_function,
  function
]
is_not: [polynomial_equation]
why:
  polynomial_equation: >-
    $f(x) = x^2 - 1$ is not a polynomial equation, because its equals sign defines $f$ instead of posing an equation to be solved.
  polynomial_function: >-
    $f(x) = x^2 - 1$ for $x \in \reals$ is a polynomial function because it evaluates a polynomial at each real number.
---
