title: 'The functions $f_n(x) = x^n$ on $[0, 1)$, as $n \to \infty$'
detail: >-
  The sequence of functions $f_1(x) = x$, $f_2(x) = x^2$, $f_3(x) = x^3$, $\dots$, each defined for $x$ in $[0, 1)$.
  For each fixed $x$ in the interval, $x^n \to 0$ as $n \to \infty$.
level: undergraduate
is_not: [uniform_in_parameter, uniform_convergence]
why:
  uniform_in_parameter: >-
    $x^n \to 0$ on $[0, 1)$, but not uniformly, because for each $n$, there are points near $1$ where $x^n$ is close to $1$.
  uniform_convergence: >-
    $x^n \to 0$ pointwise on $[0, 1)$, but not uniformly, because for every $n$, some $x$ near $1$ has $x^n > \frac{1}{2}$.
