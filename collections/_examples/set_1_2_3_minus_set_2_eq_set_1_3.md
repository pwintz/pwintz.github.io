---
title: '$\setdef{1, 2, 3} \setminus \setdef{2} = \setdef{1, 3}$'
level: elementary
is: [set_difference]
is_not: [difference]
why:
  set_difference: >-
    $\setdef{1, 2, 3} \setminus \setdef{2}$ is a set difference because it removes the elements of $\setdef{2}$ from $\setdef{1, 2, 3}$.
  difference: >-
    $\setdef{1, 2, 3} \setminus \setdef{2}$ is not a difference of numbers, because removing elements is not subtraction.
---
