title: '$3x + 2 = 8$'
level: high-school
is: [equation]
is_not: [
  expression,
  identity_equation
]
why:
  identity_equation: >-
    $3x + 2 = 8$ is not an identity, because it is true only for $x = 2$.
  expression: >-
    $3x + 2 = 8$ is an equation because it says that two expressions are equal.
---
