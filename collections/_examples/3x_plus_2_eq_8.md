published: false
title: '$3x + 2 = 8$'
level: high-school
is: [
  equation,
  expression_logic
]
is_not: [
  expression,
  identity_equation
]
why:
  identity_equation: >-
    $3x + 2 = 8$ is not an identity, because it is true only for $x = 2$.
  expression: >-
    $3x + 2 = 8$ is not an expression, because it is an equation: it says that the two expressions $3x + 2$ and $8$ are equal.
  expression_logic: >-
    $3x + 2 = 8$ is an expression in the logic sense, because $3x + 2 = 8$ is a well-formed string of symbols, namely a formula.
---
