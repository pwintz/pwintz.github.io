---
title: '$0$'
level: elementary
is: [natural_numbers_from_zero, whole_numbers, zero_number]
is_not: [natural_numbers_from_one, empty_set, zero_vector]
why:
  zero_vector: >-
    The number $0$ is not a zero vector, because it is a number, not a vector.
  natural_numbers_from_one: >-
    $0$ is a natural number when the natural numbers start at $0$, but not when they start at $1$.
    It is the only number on which the two conventions disagree.
  natural_numbers_from_zero: >-
    $0$ is a whole number and a natural number (when the natural numbers start at $0$).
    It is not a natural number when the natural numbers start at $1$.
---
