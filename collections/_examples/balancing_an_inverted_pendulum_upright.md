title: 'Balancing an inverted pendulum upright'
level: high-school
is: [stabilization, regulation]
is_not: [tracking]
why:
  stabilization: >-
    Balancing the pendulum is stabilization because the upright position is an unstable equilibrium that feedback must make asymptotically stable.
  regulation: >-
    Balancing an inverted pendulum upright is regulation, because the upright position is a constant set point.
  tracking: >-
    Balancing an inverted pendulum upright is not tracking, because the reference does not change over time.
---
