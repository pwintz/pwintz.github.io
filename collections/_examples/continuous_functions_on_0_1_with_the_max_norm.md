title: 'Continuous functions on $[0, 1]$ with the max norm'
level: graduate
is: [metric_space, normed_space, banach_space]
is_not: [inner_product_space, hilbert_space]
why:
  metric_space: >-
    The continuous functions with the max norm form a normed space, and so a metric space, and it is complete, so it is a Banach space.
  inner_product_space: >-
    The continuous functions on $[0, 1]$ with the max norm are not an inner product space or a Hilbert space, because the max norm fails the parallelogram law.
