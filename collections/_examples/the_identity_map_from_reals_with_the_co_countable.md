title: 'The identity map from $\reals$ with the co-countable topology to $\reals$ with the discrete topology'
level: undergraduate
is: [sequentially_continuous]
is_not: [continuous]
why:
  sequentially_continuous: >-
    The identity map from $\reals$ with the co-countable topology to $\reals$ with the discrete topology is sequentially continuous, because only eventually constant sequences converge in the co-countable topology.
  continuous: >-
    The identity map from $\reals$ with the co-countable topology to $\reals$ with the discrete topology is not continuous, because every singleton is open in the discrete topology, but its preimage is not open in the co-countable topology.
