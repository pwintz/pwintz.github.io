title: '$\omega + 1$'
level: graduate
is: [ordinal_number]
is_not: [cardinal_number]
why:
  ordinal_number: >-
    $\omega + 1$ is an ordinal number: it comes right after $\omega$ in the order of ordinals.
  cardinal_number: >-
    $\omega + 1$ is not a new cardinal number, because a set of order type $\omega + 1$ has the same cardinality, $\aleph_0$, as a set of order type $\omega$.
---
