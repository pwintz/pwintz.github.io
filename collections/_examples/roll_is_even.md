---
published: false
title: '"The roll is even," for a roll $X$ of a fair die'
level: high-school
is: [event]
is_not: [random_variable]
why:
  event: >-
    "The roll is even" is an event, the set of outcomes $\setdef{2, 4, 6}$, which has probability $\frac{1}{2}$.
  random_variable: >-
    "The roll is even" is not a random variable, because it is a set of outcomes, not a number assigned to each outcome.
---
