published: false
title: '$x \mapsto x^2$'
level: high-school
is: [function]
is_not: [
  graph_of_function,
  curve
]
values:
  fixed_point: '$0$ and $1$'
why:
  fixed_point: >-
    The fixed points of $x \mapsto x^2$ are $0$ and $1$, the solutions of $x^2 = x$.
  function: >-
    $x \mapsto x^2$ is a function because it is a rule that assigns one output to each input.
  graph_of_function: >-
    $x \mapsto x^2$ is not a graph, because it is a rule, not a set of points.
  curve: >-
    $x \mapsto x^2$ is not a curve, because it is a rule, not a set of points.
---
