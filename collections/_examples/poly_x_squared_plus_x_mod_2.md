title: '$x^2 + x$, with coefficients in $\setdef{0, 1}$ and arithmetic modulo $2$'
level: graduate
is: [polynomial]
values:
  polynomial_function: 'The zero function'
why:
  polynomial_function: >-
    The polynomial $x^2 + x$ with arithmetic modulo $2$ gives the zero function, because $0^2 + 0 = 0$ and $1^2 + 1 = 0$.
    $0^2 + 0 = 0$ and $1^2 + 1 = 2 = 0$, so the nonzero polynomial gives the same function as the polynomial $0$.
  polynomial: >-
    $x^2 + x$ is a nonzero polynomial over $\setdef{0, 1}$.
