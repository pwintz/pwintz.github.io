title: 'A uniform random number $X$ on $[0, 1]$'
level: undergraduate
values:
  discrete_distribution: 'No'
  continuous_distribution: 'Yes'
  mixed_distribution: 'No'
  singular_distribution: 'No'
  probability_density: '$f(x) = 1$ for $0 \leq x \leq 1$, and $0$ otherwise'
  cumulative_distribution_function: '$F(x) = x$ for $0 \leq x \leq 1$'
  probability_mass_function: 'None'
why:
  probability_density: >-
    A uniform random number on $[0, 1]$ has density $1$ on $[0, 1]$, because the probability of each subinterval equals its length.
  cumulative_distribution_function: >-
    The cumulative distribution function of a uniform random number on $[0, 1]$ is $F(x) = P(X \leq x) = x$ on $[0, 1]$, the length of $[0, x]$.
  probability_mass_function: >-
    A uniform random number on $[0, 1]$ has no probability mass function, because every single value has probability $0$.
  discrete_distribution: >-
    A uniform random number on $[0, 1]$ does not have a discrete distribution, because every single value has probability $0$.
  continuous_distribution: >-
    A uniform random number on $[0, 1]$ has a continuous distribution, with density $1$ on $[0, 1]$.
  mixed_distribution: >-
    A uniform random number on $[0, 1]$ does not have a mixed distribution, because no single value has positive probability.
  singular_distribution: >-
    A uniform random number on $[0, 1]$ does not have a singular distribution, because every set of length $0$ has probability $0$.
