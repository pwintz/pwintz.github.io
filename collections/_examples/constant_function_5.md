---
title: '$x \mapsto 5$'
level: high-school
is: [
  constant_function,
  idempotent
]
why:
  constant_function: >-
    $x \mapsto 5$ is a constant function, because it gives the same output, $5$, for every input.
  fixed_point: >-
    The only fixed point of $x \mapsto 5$ is $5$.
  idempotent: >-
    $x \mapsto 5$ is idempotent, because applying it twice still gives $5$.
---
