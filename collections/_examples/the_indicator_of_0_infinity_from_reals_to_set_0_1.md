published: false
title: 'The indicator of $[0, \infty)$, from $\reals$ to $\setdef{0, 1}$ with the discrete topology'
level: undergraduate
is: [
  open_map,
  closed_map
]
is_not: [continuous]
why:
  continuous: >-
    The indicator is not continuous, because the preimage of the open set $\setdef{1}$ is $[0, \infty)$, which is not open.
  closed_map: >-
    The indicator is an open map and a closed map because every subset of a discrete space is open and closed.
---
