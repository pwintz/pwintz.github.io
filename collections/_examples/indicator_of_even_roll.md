---
published: false
title: 'The indicator $\mathbf{1}_{\text{even}}$, which is $1$ if a die roll is even and $0$ otherwise'
level: undergraduate
is: [random_variable]
is_not: [event]
why:
  random_variable: >-
    The indicator of an even roll is a random variable, because it assigns the number $1$ or $0$ to each outcome.
  event: >-
    The indicator of an even roll is not an event itself, but it encodes the event $\setdef{2, 4, 6}$: the event happens exactly when the indicator is $1$.
---
