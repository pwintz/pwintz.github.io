---
title: '$\sin^2 x + \cos^2 x = 1$'
level: high-school
is: [
  equation,
  identity_equation
]
is_not: [expression]
why:
  identity_equation: >-
    $\sin^2 x + \cos^2 x = 1$ is an identity because it is true for every $x$.
  expression: >-
    $\sin^2 x + \cos^2 x = 1$ is an equation because it says that two expressions are equal.
---
