---
title: '"$x > 3$"'
level: high-school
is: [
  predicate,
  formula_logic,
  expression
]
is_not: [
  proposition,
  relation,
  sentence_logic,
  propositional_formula,
  term_logic
]
why:
  predicate: >-
    "$x > 3$" is a predicate because its truth depends on $x$.
  relation: >-
    "$x > 3$" is not a relation, which is a set of pairs.
  proposition: >-
    "$x > 3$" is not a proposition, because it is not true or false until $x$ is given.
  sentence_logic: >-
    "$x > 3$" is not a sentence, because $x$ is a free variable.
  propositional_formula: >-
    "$x > 3$" is not a propositional formula, because its variable $x$ stands for a number, not for a proposition.
  formula_logic: >-
    "$x > 3$" is a formula, because "$x > 3$" applies the relation symbol $>$ to the terms $x$ and $3$.
  expression: >-
    "$x > 3$" is an expression in the logic sense, because "$x > 3$" is a well-formed string of symbols; the expression is a formula, not a term.
  term_logic: >-
    "$x > 3$" is not a term, because "$x > 3$" makes a claim about $x$ instead of naming an object.
---
