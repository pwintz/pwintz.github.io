---
published: false
title: '"$x > 3$"'
level: high-school
is: [predicate]
is_not: [proposition, relation, sentence_logic]
why:
  predicate: >-
    "$x > 3$" is a predicate because its truth depends on $x$.
  relation: >-
    "$x > 3$" is not a relation, which is a set of pairs.
  proposition: >-
    "$x > 3$" is not a proposition, because it is not true or false until $x$ is given.
  sentence_logic: >-
    "$x > 3$" is not a sentence, because $x$ is free.
---
