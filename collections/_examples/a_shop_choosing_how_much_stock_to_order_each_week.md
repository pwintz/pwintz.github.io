title: 'A shop choosing how many items to order each week, with random weekly demand, to maximize the long-run profit'
level: undergraduate
is: [markov_decision_process]
why:
  markov_decision_process: >-
    A shop choosing how many items to order each week is a Markov decision process, with the stock level as the state and the order size as the action, because next week's stock depends only on this week's stock, the order, and the random demand, and each week earns a profit.
