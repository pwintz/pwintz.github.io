---
title: 'A velocity, in meters per second'
level: high-school
is: [vector]
is_not: [covector]
values:
  physical_dimension: '$[v] = \mathsf{L} \mathsf{T}^{-1}$'
why:
  vector: >-
    A velocity is a vector because it is an arrow in space, with units of length per time.
  covector: >-
    A velocity, in meters per second, is not a covector, because it does not take a vector and return a number.
---
