level: high-school
is: [
  closed_loop,
  feedforward,
  feedback
]
why:
  closed_loop: >-
    Cruise control that uses the speed error is closed-loop feedback control, because it corrects the measured speed error.
  feedforward: >-
    Cruise control that uses a map of upcoming hills is feedforward control, because it uses the map to anticipate the hills.
