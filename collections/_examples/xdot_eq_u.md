published: false
title: '$\dot{x} = u$'
level: high-school
is: [controllable, reachable, stabilizable]
why:
  stabilizable: >-
    $\dot{x} = u$ is stabilizable, for example with $u = -x$.
  controllable: >-
    $\dot{x} = u$ is controllable and reachable because any state can be steered to any other, for example with a constant input.
---
