title: 'The ordinals $[0, \omega_1)$ with the order topology'
level: graduate
is: [sequentially_compact, locally_compact]
is_not: [compact, paracompact]
why:
  sequentially_compact: >-
    $[0, \omega_1)$ is sequentially compact because every sequence is bounded below $\omega_1$, so it lies in a compact interval, and it is locally compact.
  paracompact: >-
    The ordinals $[0, \omega_1)$ with the order topology is not compact, because the cover by the sets $[0, \alpha)$ has no finite subcover, and it is not paracompact.
