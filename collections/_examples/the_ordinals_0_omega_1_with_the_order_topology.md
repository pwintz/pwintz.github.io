title: 'The ordinals $[0, \omega_1)$ with the order topology'
level: graduate
is: [sequentially_compact, locally_compact]
is_not: [compact, paracompact]
why:
  sequentially_compact: >-
    $[0, \omega_1)$ is sequentially compact, because every sequence is bounded below $\omega_1$, so it lies in a compact interval.
  paracompact: >-
    $[0, \omega_1)$ is not paracompact, because a paracompact space that is countably compact is compact, and $[0, \omega_1)$ is not compact.
  locally_compact: >-
    $[0, \omega_1)$ is locally compact, because every point has a neighborhood $[0, \alpha]$, which is compact.
  compact: >-
    $[0, \omega_1)$ is not compact, because the cover by the sets $[0, \alpha)$ has no finite subcover.
