level: graduate
is_not: [maximal_solution, complete_solution]
why:
  maximal_solution: >-
    The restricted solution is not maximal, because it can be extended past $t = \frac{1}{2}$.
  complete_solution: >-
    The restricted solution is not complete, because it stops at $t = \frac{1}{2}$.
