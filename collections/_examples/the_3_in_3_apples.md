---
title: 'The "3" in "3 apples"'
level: elementary
is: [cardinal_number]
is_not: [
  ordinal_number,
  nominal_number
]
why:
  cardinal_number: >-
    The "3" in "3 apples" is a cardinal number because it tells how many apples there are.
  ordinal_number: >-
    The "3" in "3 apples" is not an ordinal number, because it does not give a position in a list.
  nominal_number: >-
    The "3" in "3 apples" is not a nominal number, because it is not just a label.
---
