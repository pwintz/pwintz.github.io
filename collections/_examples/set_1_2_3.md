---
title: '$\setdef{1, 2, 3}$'
level: high-school
is: [
  finite_set,
  bounded,
  compact,
  countable
]
is_not: [
  sequence,
  uncountable
]
values:
  cardinality: '$\abs{\setdef{1, 2, 3}} = 3$'
why:
  sequence: >-
    $\setdef{1, 2, 3}$ is not a sequence, because a set has no order, but a sequence lists its terms in order.
  finite_set: >-
    $\setdef{1, 2, 3}$ is finite because it has $3$ elements.
  uncountable: >-
    $\setdef{1, 2, 3}$ is not uncountable, because it is finite.
  bounded: >-
    $\setdef{1, 2, 3}$ is bounded, because all of its elements are between $1$ and $3$.
  countable: >-
    $\setdef{1, 2, 3}$ is countable, because it is finite.
  compact: >-
    $\setdef{1, 2, 3}$ is compact, because it is finite, and every finite subset of $\reals$ is compact.
---
