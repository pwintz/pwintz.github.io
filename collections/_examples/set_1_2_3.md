---
title: '$\setdef{1, 2, 3}$'
level: high-school
is: [
  finite_set,
  bounded,
  compact,
  countable
]
is_not: [
  sequence,
  uncountable
]
values:
  cardinality: '$\abs{\setdef{1, 2, 3}} = 3$'
why:
  sequence: >-
    A set has no order. A sequence lists its terms in order.
  finite_set: >-
    $\setdef{1, 2, 3}$ is finite because it has $3$ elements.
  uncountable: >-
    $\setdef{1, 2, 3}$ is not uncountable, because it is finite.
  bounded: >-
    $\setdef{1, 2, 3}$ is a finite set, so it is bounded and compact, as is every finite subset of $\reals$.
  countable: >-
    $\setdef{1, 2, 3}$ is countable, because it is finite.
---
