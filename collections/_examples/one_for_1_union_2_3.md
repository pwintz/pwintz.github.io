title: 'The point $1$, for the set $\setdef{1} \cup [2, 3]$'
level: high-school
is: [
  isolated_point,
  adherent_point
]
is_not: [limit_point]
why:
  isolated_point: >-
    The point $1$ is an isolated point of $\setdef{1} \cup [2, 3]$, because the interval $(0, 2)$ around $1$ meets the set only at $1$.
  adherent_point: >-
    The point $1$ is an adherent point of $\setdef{1} \cup [2, 3]$, because $1$ belongs to the set.
  limit_point: >-
    The point $1$ is not a limit point of $\setdef{1} \cup [2, 3]$, because the interval $(0, 2)$ around $1$ contains no point of the set other than $1$.
---
