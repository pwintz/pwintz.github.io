---
published: false
title: '$(1, 2, 2)$'
level: high-school
is: [
  sequence,
  indexed_family
]
is_not: [
  set,
  multiset
]
why:
  multiset: >-
    Order matters in a sequence: $(1, 2, 2) \neq (2, 1, 2)$, but they are the same multiset.
  set: >-
    $(1, 2, 2)$ is not a set, because its order matters.
  sequence: >-
    $(1, 2, 2)$ is a sequence of length three, and so an indexed family, which is different from $(2, 1, 2)$ and from $(1, 2)$.
---
