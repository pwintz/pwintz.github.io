title: '$\setdef{\setdef{1}, \setdef{2}, \setdef{3}}$, compared with $\setdef{\setdef{1, 2}, \setdef{3}}$'
level: high-school
is: [
  set_partition,
  refinement
]
why:
  set_partition: >-
    $\setdef{\setdef{1}, \setdef{2}, \setdef{3}}$ is a partition of $\setdef{1, 2, 3}$.
  refinement: >-
    $\setdef{\setdef{1}, \setdef{2}, \setdef{3}}$ is a refinement of $\setdef{\setdef{1, 2}, \setdef{3}}$ because each of its blocks is contained in a block of the other.
