---
title: 'The set $\setdef{A, B}$ of $2$ of the letters $A$, $B$, and $C$'
level: high-school
is: [combination]
is_not: [permutation]
why:
  combination: >-
    The set $\setdef{A, B}$ is a combination of $2$ of the letters $A$, $B$, and $C$, because it contains $2$ different letters, with no order.
  permutation: >-
    The set $\setdef{A, B}$ is not a permutation, because a set does not list its elements in an order: $\setdef{A, B}$ and $\setdef{B, A}$ are the same set.
---
