title: '$\emptyset$ and $\setdef{1, 2}$'
level: elementary
is: [subset, proper_subset]
is_not: [element_of]
why:
  element_of: >-
    $\emptyset$ is not an element of $\setdef{1, 2}$, because $\emptyset$ is an element only of sets that list it.
  proper_subset: >-
    $\emptyset$ is a proper subset, and so a subset, of $\setdef{1, 2}$, because the empty set is a subset of every set and $\emptyset \neq \setdef{1, 2}$.
