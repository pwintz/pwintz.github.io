title: Well-posed problem
term: well-posed
applies_to: problems (such as PDEs with boundary or initial conditions)
levels:
  high-school:
    text: |-
      Consider a mathematical problem, such as a differential equation with given data.
      The problem is _well-posed_ if

      1. the problem has a solution,
      2. the problem has only one solution, and
      3. small changes in the data cause only small changes in the solution.
  undergraduate:
    text: |-
      Consider a problem whose solution depends on some data.
      The problem is _well-posed_ (in the sense of Hadamard) if

      1. a solution exists,
      2. the solution is unique, and
      3. the solution depends continuously on the data, so small changes in the data cause small changes in the solution.
