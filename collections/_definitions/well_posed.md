title: Well-posed problem
term: well-posed
applies_to: problems (such as PDEs with boundary or initial conditions)
levels:
  high-school:
    text: |-
      A problem is _well-posed_ if it has a solution, only one solution, and small changes in the data cause only small changes in the solution.
  undergraduate:
    text: |-
      A problem is _well-posed_ (in the sense of Hadamard) if a solution exists, the solution is unique, and the solution depends continuously on the data, so small changes in the data cause small changes in the solution.
---
