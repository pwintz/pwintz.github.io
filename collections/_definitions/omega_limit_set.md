title: Omega-limit set
term: "ω-limit set"
applies_to: solutions of dynamical systems
synonyms: [$\omega(x)$]
levels:
  graduate:
    text: |-
      The _ω-limit set_ of a point $x$ is the set of all points $z$ such that $\phi(t_n, x) \to z$ for some [sequence](/definitions/sequence) of times $t_n \to \infty$, where $\phi(t, x)$ is the solution starting at $x$. It describes where the solution ends up.
properties:
  - >-
    If the solution starting at $x$ is [bounded](/definitions/bounded), its ω-limit set is nonempty, [compact](/definitions/compact), connected, and invariant, and the solution converges to it.
  - >-
    The α-limit set is defined the same way, with $t_n \to -\infty$.
