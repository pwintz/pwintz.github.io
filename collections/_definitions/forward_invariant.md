title: Forward invariant set
term: forward invariant
applies_to: sets and dynamical systems
synonyms: [positively invariant]
levels:
  high-school:
    text: |-
      A set of states is _forward invariant_ if a system that starts in it never leaves it.
  undergraduate:
    text: |-
      A set $S$ is _forward invariant_ for $\dot{x} = f(x)$ if every solution that starts in $S$ stays in $S$ for all future time.
  graduate:
    context: systems with nonunique solutions
    text: |-
      A set $S$ is _strongly forward invariant_ (or just forward invariant) if _every_ solution starting in $S$ stays in $S$, and _weakly forward invariant_ if, from each point of $S$, _at least one_ solution stays in $S$.
