title: Forward invariant set
term: forward invariant
applies_to: sets and dynamical systems
synonyms: [positively invariant]
levels:
  high-school:
    text: |-
      Consider a system whose state changes over time, and a set of states.
      The set is _forward invariant_ if the system never leaves it after starting in it.
  undergraduate:
    text: |-
      Consider a system $\dot{x} = f(x)$ and a set $S$ of states.
      The set $S$ is _forward invariant_ if every solution that starts in $S$ stays in $S$ for all future time.
  graduate:
    context: systems with nonunique solutions
    text: |-
      Consider a system whose solutions may be nonunique, and a set $S$ of states.
      The set $S$ is _strongly forward invariant_ (or just forward invariant) if _every_ solution starting in $S$ stays in $S$, and _weakly forward invariant_ if, from each point of $S$, _at least one_ solution stays in $S$.
