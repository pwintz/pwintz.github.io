title: Removable discontinuity
term: removable discontinuity
applies_to: functions
levels:
  high-school:
    text: |-
      Consider a function $f$ and a point $a$.
      The function $f$ has a _removable discontinuity_ at $a$ if the graph of $f$ approaches a single height as $x$ approaches $a$, but $f(a)$ is a different height or is undefined, so the graph has a hole at $a$.
  undergraduate:
    text: |-
      Consider a function $f$ defined near a point $a$.
      The function $f$ has a _removable discontinuity_ at $a$ if the [limit](/dictionary/definitions/limit-of-function) $L = \lim_{x \to a} f(x)$ exists and

      $$f(a) \neq L \quad \text{or} \quad f(a) \text{ is undefined}.$$
properties:
  - >-
    Redefining $f(a) = L$ removes the discontinuity: the redefined function is [continuous](/dictionary/definitions/continuous) at $a$.
