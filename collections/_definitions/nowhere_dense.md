title: Nowhere dense set
term: nowhere dense
applies_to: sets
levels:
  graduate:
    context: topology
    text: |-
      A set $A$ is _nowhere dense_ if the interior of its closure is empty: $\operatorname{int}(\overline{A}) = \emptyset$.
properties:
  - >-
    $A$ is nowhere dense if and only if every nonempty open set contains a nonempty open [subset](/definitions/subset) that misses $A$.
  - >-
    [Subsets](/definitions/subset) and closures of nowhere dense sets are nowhere dense, and a finite [union](/definitions/set-union) of nowhere dense sets is nowhere dense.
