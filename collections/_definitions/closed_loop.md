---
title: Closed-loop control
term: closed loop
applies_to: control systems
levels:
  elementary:
    text: |-
      Think of a machine that is trying to reach a goal, like a heater warming a room.
      In _closed-loop_ control, the machine checks the result and adjusts its action based on what it measures.
  high-school:
    text: |-
      Consider a controller that chooses the input to a system.
      In _closed-loop_ control, the controller measures the result and adjusts the input to correct errors.
  undergraduate:
    text: |-
      Consider a control system $\dot x = f(x, u)$. 
      In _closed-loop_ control, the input $u$ is computed from measurements of the output (or state), forming a [feedback](/definitions/feedback) loop.
      The _closed-loop system_ is the plant together with its controller.
---
