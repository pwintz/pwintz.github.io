title: Group
term: group
applies_to: algebraic structures
levels:
  high-school:
    text: |-
      A _group_ is a set with a way of combining two elements that is associative, has an element that changes nothing, and lets every element be undone.
  undergraduate:
    context: abstract algebra
    text: |-
      A _group_ is a set $G$ with a [binary operation](/definitions/binary-operation) $\ast$ that is associative, has an [identity element](/definitions/identity-element) $e$ (with $e \ast g = g \ast e = g$ for all $g$), and in which every element $g$ has an inverse $g^{-1}$ (with $g \ast g^{-1} = g^{-1} \ast g = e$).
properties:
  - >-
    The [identity element](/definitions/identity-element) of a group is unique, and so is the inverse of each element.
---
In mathematics, "group" is a technical term. Avoid using it informally to mean "a bunch of objects."
