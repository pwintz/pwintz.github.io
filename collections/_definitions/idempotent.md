title: Idempotent
term: idempotent
applies_to: elements and functions
levels:
  high-school:
    text: |-
      An operation is _idempotent_ if doing it twice gives the same result as doing it once.
  undergraduate:
    text: |-
      An element $x$ is _idempotent_ if $x \ast x = x$. A function $f$ is _idempotent_ if $f \circ f = f$: applying it twice is the same as applying it once. Examples include projections, absolute value, and rounding.
