title: Oscillating discontinuity
term: oscillating discontinuity
applies_to: functions
synonyms: [oscillatory discontinuity]
levels:
  undergraduate:
    text: |-
      Consider a function $f$ defined near a point $a$.
      The function $f$ has an _oscillating discontinuity_ at $a$ if $f$ stays [bounded](/definitions/bounded) near $a$, but $f(x)$ keeps swinging between different values as $x$ approaches $a$ from at least one side, so the one-sided limit from that side does not exist.
properties:
  - >-
    The derivative of $x^2 \sin(1/x)$ (with value $0$ at $0$) has an oscillating discontinuity at $0$; by Darboux's theorem, an oscillating discontinuity is the only kind of discontinuity that a derivative can have.
