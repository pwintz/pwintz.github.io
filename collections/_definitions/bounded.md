---
title: Bounded
term: bounded
applies_to: "sets, sequences, and functions"
levels:
  elementary:
    text: |-
      A set of numbers is _bounded_ if it does not go on forever in either direction: there is some number that all of them are smaller than in size.
  high-school:
    context: sets of real numbers
    text: |-
      A set $S$ of [real numbers](/definitions/real-number) is _bounded_ if there is a number $M$ with $\lvert x \rvert \leq M$ for every $x \in S$.
  undergraduate:
    context: metric spaces
    text: |-
      A [subset](/definitions/subset) of a [metric space](/definitions/metric-space) is _bounded_ if it is contained in some [ball](/definitions/ball). A [sequence](/definitions/sequence) or function is _bounded_ if its set of values is bounded.
