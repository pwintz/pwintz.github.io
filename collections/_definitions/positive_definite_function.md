---
title: Positive definite function
term: positive definite function
applies_to: functions
levels:
  graduate:
    text: |-
      Consider a function $V : D \to \reals$ whose domain $D$ contains $0$.
      The function $V$ is _positive definite_ if $V(0) = 0$ and $V(x) > 0$ for all $x \neq 0$ in $D$.
---
A [symmetric matrix](/dictionary/definitions/symmetric-matrix) $P$ is positive definite if $x^{\top} P x > 0$ for all $x \neq 0$, which says exactly that the function $V(x) = x^{\top} P x$ is positive definite.
Positive definite functions in harmonic analysis (Bochner's theorem) are something else.
