title: Plane Wave
term: plane wave
applies_to: waves
levels:
  high-school:
    text: |-
      A _plane wave_ is a [wave](/dictionary/definitions/wave) whose peaks are parallel flat planes, which all travel in the same direction, perpendicular to the planes.
  undergraduate:
    text: |-
      Consider a [wave](/dictionary/definitions/wave) $u(\vect{x}, t)$ in space, and a [unit vector](/dictionary/definitions/unit-vector) $\vect{n}$.
      The wave $u$ is a _plane wave_ traveling in the direction of $\vect{n}$ with speed $c$ if, for some function $f$,

      $$u(\vect{x}, t) = f(\vect{n} \cdot \vect{x} - c t).$$
properties:
  - |-
    A sinusoidal plane wave is $A \cos(\vect{k} \cdot \vect{x} - \omega t + \phi)$, where the _wave vector_ $\vect{k}$ points in the direction of travel and has length $2\pi / \lambda$.
  - |-
    A plane wave is constant on each plane perpendicular to $\vect{n}$.
  - |-
    Far from a small source, the [wave](/dictionary/definitions/wave) from the source is close to a plane wave over a region that is small compared to the distance to the source.
  - |-
    A plane wave fills all of space with the same [amplitude](/dictionary/definitions/amplitude), so a plane wave carries infinite [energy](/dictionary/definitions/energy) and is an idealization.
