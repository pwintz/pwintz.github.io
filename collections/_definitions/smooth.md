title: Smooth function
term: smooth
applies_to: functions
synonyms: ["$C^{\\infty}$", infinitely differentiable]
levels:
  high-school:
    text: |-
      A function is _smooth_ if you can take as many derivatives of it as you like, and each derivative is [continuous](/definitions/continuous).
  undergraduate:
    text: |-
      A function is _smooth_ if it has [continuous](/definitions/continuous) derivatives of every order.
---
Some authors use "smooth" loosely to mean "[continuously differentiable](/definitions/continuously-differentiable)" or "as [differentiable](/definitions/differentiable) as needed." Check the author's definition.
