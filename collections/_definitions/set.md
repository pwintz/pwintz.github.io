title: Set
term: set
applies_to: collections
levels:
  elementary:
    text: |-
      A _set_ is a collection of different objects, called its elements. Order and repetition do not matter: $\lbrace 1, 2 \rbrace$, $\lbrace 2, 1 \rbrace$, and $\lbrace 1, 1, 2 \rbrace$ are the same set.
  graduate:
    context: axiomatic set theory
    text: |-
      A _set_ is an object of a set theory such as ZFC. By the axiom of extensionality, a set is determined entirely by its elements.
properties:
  - >-
    Not every collection is a set: the collection of all sets is not a set (Russell's paradox).
