---
title: Uncountable set
term: uncountable
applies_to: sets
synonyms: [uncountably infinite]
levels:
  high-school:
    text: |-
      Consider an infinite set $S$. 
      The set is _uncountable_ if it is impossible to list the elements of $S$ in an (infinite) list $a_1, a_2, a_3, \dots$. The set is so large that every such list must leave out some elements of $S$.
  undergraduate:
    text: |-
      Consider an infinite set $S$.
      The set $S$ is _uncountable_ if there does not exist a [surjection](/dictionary/definitions/surjection) from $\nats$ onto $S$.
properties:
  - >-
    $\reals$ is uncountable (Cantor's diagonal argument), and so is every interval with more than one point.
---
