title: Uncountable set
term: uncountable
applies_to: sets
synonyms: [uncountably infinite]
levels:
  high-school:
    text: |-
      A set is _uncountable_ if it is so large that no infinite list $a_1, a_2, a_3, \dots$ can include all of its elements.
  undergraduate:
    text: |-
      A set is _uncountable_ if it is infinite but not [countably infinite](/definitions/countably-infinite): no list $a_1, a_2, a_3, \dots$ contains all of its elements.
properties:
  - >-
    $\reals$ is uncountable (Cantor's diagonal argument), and so is every interval with more than one point.
