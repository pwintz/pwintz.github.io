title: Uncountable set
term: uncountable
applies_to: sets
synonyms: [uncountably infinite]
levels:
  high-school:
    text: |-
      Consider an infinite set, and try to list its elements as $a_1, a_2, a_3, \dots$ The set is _uncountable_ if it is so large that no such list can include all of its elements.
  undergraduate:
    text: |-
      Consider an infinite set $S$.
      The set $S$ is _uncountable_ if it is not [countably infinite](/definitions/countably-infinite): no list $a_1, a_2, a_3, \dots$ contains all of its elements.
properties:
  - >-
    $\reals$ is uncountable (Cantor's diagonal argument), and so is every interval with more than one point.
