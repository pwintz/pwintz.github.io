---
title: Zero vector
term: zero vector
applies_to: vector spaces
synonyms: ["$\\mathbf{0}$"]
levels:
  elementary:
    text: |-
      Think of [vectors](/definitions/vector) as arrows, which can be long or short.
      The _zero vector_ is the arrow with length zero.
      It does not point in any direction and adding it using the tip-to-tail rule does not change the vector it is added to.
  high-school:
    text: |-
      The _zero vector_ is the [vector](/definitions/vector) whose components are all zero.
  undergraduate:
    text: |-
      Consider a [vector](/definitions/vector) space $V$, with its vector addition.
      The _zero vector_ of $V$ is its additive identity: the vector $\mathbf{0}$ with

      $$v + \mathbf{0} = v \quad \text{for every } v \in V.$$

      In a space of functions, it is the function that is $0$ everywhere.
properties:
  - >-
    The zero vector is the only [vector](/definitions/vector) with length zero, and it has no direction.
---
