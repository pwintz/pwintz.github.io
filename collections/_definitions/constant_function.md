title: Constant function
term: constant
applies_to: functions
levels:
  elementary:
    text: |-
      Think of a function as a machine that takes an input and gives an output.
      The function is _constant_ if it gives the same output for every input.
  high-school:
    text: |-
      Consider a function $f$.
      The function is _constant_ if $f(x) = c$ for every $x$ in its domain, for some fixed $c$.
