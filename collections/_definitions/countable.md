---
title: Countable set
term: countable
applies_to: sets
synonyms: [at most countable]
levels:
  high-school:
    text: |-
      Consider a set, and try to list its elements one after another, as $a_1, a_2, a_3, \dots$ (possibly stopping after finitely many or continuing forever).
      The set is _countable_ if this can be done so that every element appears in the list.
  undergraduate:
    text: |-
      Consider a set $S$.
      The set $S$ is _countable_ if $S$ is [finite](/dictionary/definitions/finite-set) or [countably infinite](/dictionary/definitions/countably-infinite): equivalently, if there is an [injective](/dictionary/definitions/injective) map from $S$ to $\nats$.
properties:
  - |-
    Every [subset](/dictionary/definitions/subset) of a countable set is countable.
  - |-
    A countable [union](/dictionary/definitions/set-union) of countable sets is countable (assuming the axiom of countable choice), so $\mathbb{Z}$ and $\mathbb{Q}$ are countable.
---
"Countable" is ambiguous: some authors use it to mean [countably infinite](/dictionary/definitions/countably-infinite), excluding finite sets.
When it matters, say "finite or countably infinite" or "at most countable."
