title: Linear system
term: linear (system)
applies_to: dynamical systems
levels:
  high-school:
    text: |-
      A system is _linear_ if, starting from rest, doubling the input doubles the response, and the response to a sum of inputs is the sum of the responses.
  undergraduate:
    text: |-
      A system is _linear_ if its equations are linear in the state and input: $\dot{x} = A(t) x + B(t) u$ and $y = C(t) x + D(t) u$.
properties:
  - >-
    Linear systems satisfy the superposition principle: the response to $a u_1 + b u_2$ from the initial state $a x_1 + b x_2$ is $a$ times the response to $u_1$ from $x_1$ plus $b$ times the response to $u_2$ from $x_2$.
