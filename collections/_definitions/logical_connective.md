title: Logical connective
term: logical connective
applies_to: statements
synonyms: [connective, connectives, logical operator]
levels:
  high-school:
    text: |-
      A _logical connective_ is a word or symbol that combines statements into a new statement, such as "not," "and," "or," and "if … then."
      For example, "and" combines "$7$ is prime" and "$7$ is odd" into "$7$ is prime and $7$ is odd."
  undergraduate:
    context: logic
    text: |-
      A _logical connective_ is a symbol that builds a formula from one or more formulas such that the truth value of the new formula is determined by the truth values of its parts.
      The usual connectives are

      1. negation $\neg p$ ("not $p$"),
      2. conjunction $p \land q$ ("$p$ and $q$"),
      3. disjunction $p \lor q$ ("$p$ or $q$"),
      4. implication $p \implies q$ ("if $p$, then $q$"), and
      5. the biconditional $p \iff q$ ("$p$ if and only if $q$").
properties:
  - >-
    Each connective is described by a truth table, which lists the truth value of the new formula for each combination of truth values of its parts.
  - >-
    In logic, "or" is inclusive: $p \lor q$ is true when $p$ and $q$ are both true.
  - >-
    The implication $p \implies q$ is true whenever $p$ is false.
