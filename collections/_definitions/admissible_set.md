title: Admissible set
term: admissible set
applies_to: state constraints
synonyms: [constraint set]
levels:
  graduate:
    context: control systems
    text: |-
      The _admissible set_ is the set of states that satisfy the state constraints, such as a minimum distance to an obstacle.
properties:
  - >-
    Being in the admissible set now does not guarantee that the constraints can be satisfied in the future. The states from which they can be satisfied forever form the [viability kernel](/definitions/viability-kernel): the largest [controlled invariant](/definitions/controlled-invariant) [subset](/definitions/subset) of the admissible set.
---
"Admissible" is also used for inputs (admissible controls are those satisfying the input constraints), which is a different use.
