---
title: Weighted average
term: weighted average
applies_to: data
synonyms: [weighted mean]
levels:
  elementary:
    text: |-
      A _weighted average_ is an average in which some values count more than others.
  high-school:
    text: |-
      The _weighted average_ of values $x_i$ with nonnegative weights $w_i$ is 
      
      $$\frac{\sum_i w_i x_i}{\sum_i w_i}.$$
      
      Values with larger weights count more.

#   undergraduate:
#     text: |-
#       The _weighted average_ of a function $f(x) : I \to \reals$ with a positive weight function $w(x)$ is 
# 
#       $$\int_I w(x) f(x) ~dx.$$

properties:
  - >-
    With equal weights, the weighted average is the ordinary mean.
  - >-
    A weighted average always lies between the smallest and largest of the values $x_i$.
---
