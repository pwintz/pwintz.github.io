title: Infinite set
term: infinite
applies_to: sets
synonyms: [infinitely many elements]
levels:
  elementary:
    text: |-
      A set is _infinite_ if it never runs out: no matter how many elements you list, there are more.
  undergraduate:
    text: |-
      A set is _infinite_ if it is not finite.
  graduate:
    context: set theory
    text: |-
      Assuming the axiom of choice, a set is _infinite_ exactly when it is in bijection with a [proper subset](/definitions/proper-subset) of itself (Dedekind infinite).
