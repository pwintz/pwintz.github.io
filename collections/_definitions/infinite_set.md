---
title: Infinite set
term: infinite
applies_to: sets
synonyms: [infinitely many elements]
levels:
  elementary:
    text: |-
      A list of items is _infinite_ if it never runs out: no matter how many elements you list, there are more.
  undergraduate:
    text: |-
      Consider a set $S$.
      The set $S$ is _infinite_ if the number of elements in $S$ is not any natural number.
  graduate:
    context: set theory
    text: |-
      Consider a set $S$, and assume the axiom of choice.
      The set $S$ is _infinite_ exactly when $S$ is in bijection with a [proper subset](/definitions/proper-subset) of itself (Dedekind infinite).
---
