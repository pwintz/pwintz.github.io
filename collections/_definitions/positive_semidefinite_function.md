title: Positive semidefinite function
term: positive semidefinite function
applies_to: functions
levels:
  graduate:
    text: |-
      Consider a function $V : D \to \reals$ whose domain $D$ contains $0$.
      The function $V$ is _positive semidefinite_ if $V(0) = 0$ and

      $$V(x) \geq 0 \quad \text{for all } x \in D.$$
---
A [positive definite function](/dictionary/definitions/positive-definite-function) is positive semidefinite, but a positive semidefinite function can also be $0$ at points other than $0$, such as $V(x_1, x_2) = x_1^2$ on $\reals^2$, which is $0$ on the whole $x_2$-axis.
