---
title: Identity element
term: identity element
applies_to: binary operations
synonyms: [neutral element]
levels:
  high-school:
    text: |-
      Consider an operation that combines two things, like addition or multiplication.
      An _identity element_ for the operation is one that leaves everything unchanged.
  undergraduate:
    text: |-
      Consider a set $S$ with a [binary operation](/dictionary/definitions/binary-operation) $\ast$.
      An _identity element_ for $\ast$ is an element $e$ such that

      $$e \ast a = a \ast e = a \quad \text{for all } a \in S.$$

      For addition, $e$ is called the _additive identity_ and is usually written as $0$.
      For multiplication, $e$ is the _multiplicative identity_ and is usually written $1$.
properties:
  - >-
    If an operation has an identity element, it is unique: if $e$ and $e^{\prime}$ are both identities, then $e = e \ast e^{\prime} = e^{\prime}$.
---
The identity element of an operation is different from the identity _function_ $x \mapsto x$, though the [identity function](/dictionary/definitions/identity-function) is the identity element for [composition](/dictionary/definitions/function-composition) of functions.
