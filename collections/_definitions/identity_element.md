title: Identity element
term: identity element
applies_to: binary operations
synonyms: [neutral element]
levels:
  high-school:
    text: |-
      An _identity element_ for an operation leaves everything unchanged.
  undergraduate:
    text: |-
      For a [binary operation](/definitions/binary-operation) $\ast$ on a set $S$, an _identity element_ is an element $e$ with $e \ast a = a \ast e = a$ for all $a \in S$. For addition, it is called the _additive identity_ (usually $0$). For multiplication, it is the _multiplicative identity_ (usually $1$).
properties:
  - >-
    If an operation has an identity element, it is unique: if $e$ and $e^{\prime}$ are both identities, then $e = e \ast e^{\prime} = e^{\prime}$.
---
The identity element of an operation is different from the identity _function_ $x \mapsto x$, though the identity function is the identity element for composition of functions.
