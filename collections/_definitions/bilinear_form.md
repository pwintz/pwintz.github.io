---
title: Bilinear form
term: bilinear form
applies_to: vector spaces
levels:
  undergraduate:
    text: |-
      Consider a [vector](/dictionary/definitions/vector) space $V$.
      The function $B : V \times V \to \reals$  is a _bilinear form_ on $V$ if $B$ is linear in each argument when the other is held fixed.
      It need not be symmetric or positive.
properties:
  # TODO: Clarify that this property is for the coordinates with respect to a particular basis. 
  - >-
    Every bilinear form on $\reals^n$ has the form $B(x, y) = x^{\top} A y$ for a unique [matrix](/dictionary/definitions/matrix) $A$, and $B$ is symmetric if and only if $A$ is.
