title: Bilinear form
term: bilinear form
applies_to: vector spaces
levels:
  undergraduate:
    text: |-
      Consider a [vector](/definitions/vector) space $V$ and a function $B : V \times V \to \reals$ that takes two vectors and returns a number.
      The function $B$ is a _bilinear form_ on $V$ if $B$ is linear in each argument when the other is held fixed.
      It need not be symmetric or positive.
properties:
  - >-
    Every bilinear form on $\reals^n$ has the form $B(x, y) = x^{\top} A y$ for a unique [matrix](/definitions/matrix) $A$, and $B$ is symmetric if and only if $A$ is.
