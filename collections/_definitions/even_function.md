title: Even function
term: even function
applies_to: functions
levels:
  high-school:
    text: |-
      A function is _even_ if $f(-x) = f(x)$ for all $x$, so its graph is symmetric about the $y$-axis. A function is _odd_ if $f(-x) = -f(x)$, so its graph is symmetric about the origin.
properties:
  - >-
    Most functions are neither even nor odd, but every function on $\reals$ is the sum of an even function and an odd function: $f(x) = \frac{f(x) + f(-x)}{2} + \frac{f(x) - f(-x)}{2}$.
  - >-
    The product of two even functions, or of two odd functions, is even.
