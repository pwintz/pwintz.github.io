title: Maximum
term: maximum
applies_to: ordered sets and functions
synonyms: [greatest element, largest element, $\max$]
levels:
  elementary:
    text: |-
      Think of a set of numbers, like the scores on a test.
      The _maximum_ of the set is the largest number in it.
    caveat: >-
      Infinite sets might not have a largest number.
      The set $[0, 1)$ has no largest element: for any $x$ in it, $(x + 1) / 2$ is larger.
  undergraduate:
    text: |-
      Consider an ordered set and a [subset](/definitions/subset) $S$ of it.
      The _maximum_ of $S$ is an element of $S$ that is greater than or equal to every element of $S$.
      The maximum of a function $f$ is the maximum of its set of values, if it exists.
properties:
  - |-
    A set has at most one maximum.
    If the maximum exists, it equals the [supremum](/definitions/supremum).
