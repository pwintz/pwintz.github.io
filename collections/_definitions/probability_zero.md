---
title: Probability zero
term: probability zero
applies_to: events
synonyms: [almost never]
levels:
  high-school:
    text: |-
      Consider an [event](/dictionary/definitions/event) in a random experiment.
      The event has _probability zero_ if its [probability](/dictionary/definitions/probability) is $0$.
  undergraduate:
    context: probability
    text: |-
      Consider a probability space with [probability measure](/dictionary/definitions/probability-measure) $P$, and an [event](/dictionary/definitions/event) $E$.
      The event $E$ has _probability zero_ if $P(E) = 0$.
properties:
  - >-
    An [event](/dictionary/definitions/event) with probability zero can still happen.
    If $X$ is uniformly distributed on $[0, 1]$, then $P(X = 1/2) = 0$, but $X$ must take some value, and every value has probability zero.
