levels:
  undergraduate:
    context: logic
    text: |-
      A _propositional formula_ is an expression built from propositional variables $p, q, r, \dots$ using connectives such as $\neg$, $\land$, $\lor$, and $\Rightarrow$. It has a truth value only once each variable is assigned true or false.
