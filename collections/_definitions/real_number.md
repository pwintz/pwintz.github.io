title: Real number
term: real number
applies_to: numbers
levels:
  elementary:
    text: |-
      The _real numbers_ are all of the numbers on the number line.
  high-school:
    text: |-
      A _real number_ is any number on the number line. Every real number can be written as a (possibly infinite) decimal.
  undergraduate:
    text: |-
      A _real number_ is an element of $\reals$, the unique complete ordered field.
properties:
  - >-
    $\reals$ can be constructed from $\mathbb{Q}$ using Dedekind cuts or Cauchy [sequences](/definitions/sequence).
  - >-
    Every nonempty set of real numbers that is [bounded](/definitions/bounded) above has a least upper bound (the completeness of $\reals$).
