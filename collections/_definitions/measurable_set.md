title: Measurable set
term: measurable set
applies_to: subsets of a measurable space
levels:
  undergraduate:
    context: measure theory
    text: |-
      Consider a set $X$ with a [σ-algebra](/definitions/sigma-algebra) $\mathcal{F}$.
      A set $A \subseteq X$ is _measurable_ if $A \in \mathcal{F}$.
    caveat: >-
      In $\reals^n$, "measurable" usually means Lebesgue measurable: in the [σ-algebra](/definitions/sigma-algebra) of sets that [Lebesgue measure](/definitions/lebesgue-measure) assigns a size to.
properties:
  - >-
    Every [open set](/definitions/open-set) and every [closed set](/definitions/closed-set) of $\reals$ is Borel, and so Lebesgue measurable.
  - >-
    Not every [subset](/definitions/subset) of $\reals$ is Lebesgue measurable: with the axiom of choice, the Vitali set has no [consistent](/definitions/consistent-scheme) length.
---
In probability, measurable sets are called [events](/definitions/event).
