title: Measurable set
term: measurable set
applies_to: subsets of a measurable space
levels:
  undergraduate:
    context: measure theory
    text: |-
      Consider a set $X$ with a [σ-algebra](/dictionary/definitions/sigma-algebra) $\mathcal{F}$.
      A set $A \subseteq X$ is _measurable_ if $A \in \mathcal{F}$.
    caveat: >-
      In $\reals^n$, "measurable" usually means Lebesgue measurable: in the [σ-algebra](/dictionary/definitions/sigma-algebra) of sets that [Lebesgue measure](/dictionary/definitions/lebesgue-measure) assigns a size to.
properties:
  - >-
    Every [open set](/dictionary/definitions/open-set) and every [closed set](/dictionary/definitions/closed-set) of $\reals$ is Borel, and so Lebesgue measurable.
  - >-
    Not every [subset](/dictionary/definitions/subset) of $\reals$ is Lebesgue measurable: with the axiom of choice, the Vitali set has no [consistent](/dictionary/definitions/consistent-scheme) length.
---
In [probability](/dictionary/definitions/probability), measurable sets are called [events](/dictionary/definitions/event).
