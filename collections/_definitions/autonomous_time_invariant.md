title: Autonomous system (time-invariant)
term: autonomous (time-invariant)
applies_to: dynamical systems
levels:
  high-school:
    text: |-
      Consider a system whose state changes over time according to some rules.
      In one convention, the system is _autonomous_ if those rules do not depend on the time on the clock.
  undergraduate:
    text: |-
      Consider a system $\dot{x} = f(t, x)$.
      In one convention, the system is _autonomous_ if its equations do not depend explicitly on time, as in $\dot{x} = f(x)$.
---
This convention is common in the theory of ordinary differential equations.
Compare [autonomous (no input)](/dictionary/definitions/autonomous-no-input).
