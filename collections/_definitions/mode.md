title: Mode
term: mode
applies_to: data and distributions
levels:
  elementary:
    text: |-
      The _mode_ of a list is the value that appears most often. A list can have several modes.
  undergraduate:
    context: probability
    text: |-
      A _mode_ of a distribution is a value at which its probability mass function (or density) is largest.
