title: Mode
term: mode
applies_to: data and distributions
levels:
  elementary:
    text: |-
      Think of a list of values, some of which may appear more than once.
      The _mode_ of the list is the value that appears most often.
      A list can have several modes.
  undergraduate:
    context: probability
    text: |-
      Consider a probability distribution, with its probability mass function (or density).
      A _mode_ of the distribution is a value at which that function is largest.
