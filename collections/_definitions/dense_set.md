title: Dense set
term: dense
applies_to: sets
levels:
  high-school:
    text: |-
      Consider a set of [real numbers](/dictionary/definitions/real-number).
      The set is _dense_ if it has members between every two different real numbers, no matter how close together the two numbers are.
  undergraduate:
    context: subsets of $\reals$
    text: |-
      Consider a set $A \subseteq \reals$.
      The set $A$ is _dense_ if every open interval, no matter how small, contains a point of $A$.
  graduate:
    context: topology
    text: |-
      Consider a topological space $X$ and a [subset](/dictionary/definitions/subset) $A$ of $X$.
      The set $A$ is _dense_ if its closure is $X$: every nonempty [open set](/dictionary/definitions/open-set) contains a point of $A$.
properties:
  - >-
    Both $\mathbb{Q}$ and $\reals \setminus \mathbb{Q}$ are dense in $\reals$.
