title: Dense set
term: dense
applies_to: sets
levels:
  high-school:
    text: |-
      Consider a set $A$ of [real numbers](/dictionary/definitions/real-number).
      The set $A$ is _dense_ if between every two different real numbers, there is a number in $A$, no matter how close together the two numbers are.
  undergraduate:
    context: subsets of $\reals$
    text: |-
      Consider a set $A \subseteq \reals$.
      The set $A$ is _dense_ if every open interval contains a point in $A$.
  graduate:
    context: topology
    text: |-
      Consider a topological space $X$ and a [subset](/dictionary/definitions/subset) $A$ of $X$.
      The set $A$ is _dense_ if its closure is $X$. 
      Equivalently: Every nonempty [open set](/dictionary/definitions/open-set) contains a point of $A$.
properties:
  - >-
    Both $\mathbb{Q}$ and $\reals \setminus \mathbb{Q}$ are dense in $\reals$.
