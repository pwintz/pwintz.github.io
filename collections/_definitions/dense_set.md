title: Dense set
term: dense
applies_to: sets
levels:
  high-school:
    text: |-
      A set of [real numbers](/definitions/real-number) is _dense_ if it has members between any two different real numbers, no matter how close together they are.
  undergraduate:
    context: subsets of $\reals$
    text: |-
      A set $A \subseteq \reals$ is _dense_ if every open interval, no matter how small, contains a point of $A$.
  graduate:
    context: topology
    text: |-
      A [subset](/definitions/subset) $A$ of a space $X$ is _dense_ if its closure is $X$: every nonempty open set contains a point of $A$.
properties:
  - >-
    Both $\mathbb{Q}$ and $\reals \setminus \mathbb{Q}$ are dense in $\reals$.
