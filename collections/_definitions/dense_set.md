---
title: Dense Set
term: dense
applies_to: sets
levels:
  high-school:
    text: |-
      Consider a set $A$ of [real numbers](/dictionary/definitions/real-number).
      Consider any two real numbers $x$ and $y$ such that $x < y$. 
      We say $A$ is _dense_ if there is always a number $a$ in $A$ such that $x < a < y,$ no matter how close together the $x$ and $y$ are.
  undergraduate:
    context: subsets of $\reals$
    text: |-
      Consider a set $A \subseteq \reals$.
      The set $A$ is _dense_ if every open interval contains a point in $A$.
  graduate:
    context: topology
    text: |-
      Consider a topological space $X$ and a [subset](/dictionary/definitions/subset) $A$ of $X$.
      The set $A$ is _dense_ if its closure is $X$. 

      Equivalently: $A$ is dense if every nonempty [open set](/dictionary/definitions/open-set) intersects $A$.
properties:
  - >-
    Both $\mathbb{Q}$ and $\reals \setminus \mathbb{Q}$ are dense in $\reals$.
---
