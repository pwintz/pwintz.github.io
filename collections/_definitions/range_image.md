title: Range (Image)
term: range (image)
applies_to: functions
levels:
  elementary:
    text: |-
      Think of a function as a machine that turns inputs into outputs.
      The _range_ of the function is the set of all of the outputs that it actually gives.
  high-school:
    text: |-
      Consider a function and all of the inputs in its domain.
      The _range_ of the function is the set of all of its outputs, one for each input in the domain.
  undergraduate:
    text: |-
      Consider a function $f : X \to Y$.
      The _range_ of $f$ is the [image](/dictionary/definitions/image) of the whole domain $X$:

      $$\range{f} = f(X) = \setdef{f(x) \suchthat x \in X}.$$
properties:
  - |-
    The dimension of the range (in this sense) of a [linear map](/dictionary/definitions/linear-map) $T$ is the [rank](/dictionary/definitions/rank-linear-map) of $T$.
  - |-
    The range (in this sense) of a [matrix](/dictionary/definitions/matrix) $A$ is its [column space](/dictionary/definitions/column-space), the set of all [vectors](/dictionary/definitions/vector) $A x$.
---
This is the most common meaning of "range," and the one used in this dictionary.
An image $f(A)$ can be taken of every set $A$ in the domain, but the range is the image of the whole domain.
See [the meanings of "range"](/dictionary/distinctions/meanings-of-range) for the other conventions.
