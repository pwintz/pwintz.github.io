---
title: Feedback
term: feedback
applies_to: control systems
synonyms: [feedback control]
levels:
  elementary:
    text: |-
      Think of a system that can see the results of what it does, like a person riding a bike.
      _Feedback_ is when the system watches its own results and adjusts.
  high-school:
    text: |-
      Consider a system with an input and an output.
      _Feedback_ is using information about the system's output to decide its input.
  undergraduate:
    text: |-
      Consider a system with an input $u$ and an output $y$ (or state $x$).
      _Feedback_ is the use of measurements of the output (or state) to determine the input, as in $u = k(y)$.
properties:
  - >-
    Feedback can stabilize unstable systems and reduce sensitivity to [disturbances](/definitions/disturbance) and model errors.
---
