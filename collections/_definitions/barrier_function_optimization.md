title: Barrier function (optimization)
term: barrier function (optimization)
applies_to: optimization problems
levels:
  undergraduate:
    text: |-
      In optimization, a _barrier function_ for the feasible set $\lbrace x : g(x) < 0 \rbrace$ is a function that is finite inside the set and tends to infinity at its [boundary](/definitions/boundary). Interior-point methods add it to the objective to keep iterates feasible.
