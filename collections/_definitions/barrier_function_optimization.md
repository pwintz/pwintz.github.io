title: Barrier function (optimization)
term: barrier function (optimization)
applies_to: optimization problems
levels:
  undergraduate:
    text: |-
      Consider an optimization problem with the feasible set $\lbrace x : g(x) < 0 \rbrace$.
      A _barrier function_ for the feasible set is a function that is finite inside the set and tends to infinity at its [boundary](/definitions/boundary).
      Interior-point methods add it to the objective to keep iterates feasible.
