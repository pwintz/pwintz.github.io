published: false
title: Limit point of a set
term: limit point
applies_to: sets
synonyms: [accumulation point, cluster point]
levels:
  high-school:
    text: |-
      Consider a set $S$ and a point $x$.
      The point $x$ is a _limit point_ of $S$ if there are points of $S$, other than $x$ itself, as close to $x$ as you like.
  undergraduate:
    text: |-
      Consider a set $S$ in a [metric space](/definitions/metric-space) and a point $x$.
      The point $x$ is a _limit point_ of $S$ if every [open ball](/definitions/open-ball) around $x$ contains a point of $S$ other than $x$.
      It need not belong to $S$.
---
For [sequences](/definitions/sequence), "limit point" sometimes means a subsequential limit, which is different.
The sequence $1, 1, 1, \dots$ has the subsequential limit $1$, but its set of values $\setdef{1}$ has no limit points.
