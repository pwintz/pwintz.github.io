---
title: Surjective function
term: surjective
applies_to: functions
synonyms: [onto]
levels:
  # elementary:
  #   text: |-
  #     A function is _surjective_ if every possible output is used by at least one input.
  high-school:
    text: |-
      A function is _surjective_ if every element of the [codomain](/definitions/codomain) is an output for some input.
  undergraduate:
    text: |-
      A function $f : X \to Y$ is _surjective_ if for every $y \in Y$ there exists $x \in X$ such that $f(x) = y$.
properties:
  - >-
    A function is surjective if and only if its image equals its [codomain](/definitions/codomain), so whether it is surjective depends on the choice of codomain.
---
