title: Lower bound
term: lower bound
applies_to: ordered sets
levels:
  elementary:
    text: |-
      Think of a set of numbers, like $\setdef{3, 5, 8}$.
      A _lower bound_ of the set is a number that is less than or equal to every number in the set.
  high-school:
    context: sets of real numbers
    text: |-
      Consider a set $S$ of [real numbers](/definitions/real-number).
      A _lower bound_ of $S$ is a number $m$ such that $m \leq x$ for every $x \in S$.
      It does not need to be in $S$, and a set can have many lower bounds.
  undergraduate:
    context: partially ordered sets
    text: |-
      Consider a partially ordered set $P$ and a [subset](/definitions/subset) $S \subseteq P$.
      A _lower bound_ of $S$ is an element $m$ of $P$ such that $m \leq x$ for every $x$ in $S$.
