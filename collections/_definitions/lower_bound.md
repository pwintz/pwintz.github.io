title: Lower bound
term: lower bound
applies_to: ordered sets
levels:
  elementary:
    text: |-
      A _lower bound_ of a set of numbers is a number that is less than or equal to all of them.
  high-school:
    context: sets of real numbers
    text: |-
      A _lower bound_ of a set $S$ is a number $m$ with $m \leq x$ for every $x \in S$. It does not need to be in $S$, and a set can have many lower bounds.
  undergraduate:
    context: partially ordered sets
    text: |-
      For a [subset](/definitions/subset) $S \subseteq P$ of a partially ordered set $P$, a _lower bound_ of $S$ is an element $m$ of $P$ with $m \leq x$ for every $x$ in $S$.
