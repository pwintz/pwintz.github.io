title: Feedforward control
term: feedforward
applies_to: control systems
levels:
  high-school:
    text: |-
      Consider a system that is affected by a [disturbance](/definitions/disturbance) that you can see coming.
      _Feedforward_ control acts on the disturbance before it affects the result.
  undergraduate:
    text: |-
      Consider a control system with a measured [disturbance](/definitions/disturbance) or a known reference signal.
      _Feedforward_ is a control action computed from the disturbance or reference, applied before the disturbance or the change in the reference affects the output.
properties:
  - >-
    Feedforward cannot correct errors it does not anticipate, such as unmeasured [disturbances](/definitions/disturbance) or model errors, so it is usually combined with [feedback](/definitions/feedback) (a two-degree-of-freedom controller).
