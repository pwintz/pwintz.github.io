title: Metric
term: metric
applies_to: sets
synonyms: [distance function]
levels:
  high-school:
    text: |-
      Consider a set of points, and a rule that gives a distance between any two of them.
      The rule is a _metric_ if no distance is negative, the distance is zero only from a point to itself, the distance is the same in both directions, and no distance is longer than a detour through a third point (the triangle inequality).
  undergraduate:
    text: |-
      Consider a set $X$ and a function $d : X \times X \to [0, \infty)$.
      The function $d$ is a _metric_ on $X$ if $d(x, y) = 0$ only for $x = y$, $d(x, y) = d(y, x)$, and $d(x, z) \leq d(x, y) + d(y, z)$ (the triangle inequality).
      The set $X$ need not be a [vector](/definitions/vector) space.
---
In differential geometry, a "metric" (Riemannian metric) is an [inner product](/definitions/inner-product) on each [tangent space](/definitions/tangent-space), not a distance function, though it determines one.
In everyday language, a "metric" is any measurement or performance indicator.
