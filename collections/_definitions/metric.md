title: Metric
term: metric
applies_to: sets
synonyms: [distance function]
levels:
  high-school:
    text: |-
      A _metric_ is a rule that gives the distance between any two points. The distance is never negative, is zero only from a point to itself, is the same in both directions, and is never shorter than a detour through a third point (the triangle inequality).
  undergraduate:
    text: |-
      A _metric_ on a set $X$ is a function $d : X \times X \to [0, \infty)$ with $d(x, y) = 0$ only for $x = y$, $d(x, y) = d(y, x)$, and $d(x, z) \leq d(x, y) + d(y, z)$ (the triangle inequality). The set $X$ need not be a [vector](/definitions/vector) space.
---
In differential geometry, a "metric" (Riemannian metric) is an [inner product](/definitions/inner-product) on each [tangent space](/definitions/tangent-space), not a distance function, though it determines one. In everyday language, a "metric" is any measurement or performance indicator.
