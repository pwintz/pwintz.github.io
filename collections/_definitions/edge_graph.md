---
title: Edge of a graph
term: edge (of a graph)
applies_to: graphs (networks)
levels:
  elementary:
    text: |-
      Imagine a network drawn as dots [connected](/definitions/connected) by lines, like a map of cities and roads.
      Each line connecting two dots in the network is called an _edge_.
  undergraduate:
    context: graph theory
    text: |-
      Consider a graph, made of a set of vertices and a set of edges.
      An _edge_ of the graph is an element of its edge set.
      In a simple undirected graph, an edge is an unordered pair $\setdef{u, v}$ of distinct vertices.
---
A graph edge has no position or length.
Drawing it as a line segment is only a convenience.
