title: Operating point
term: operating point
applies_to: control systems
synonyms: [trim point (in aerospace)]
levels:
  high-school:
    text: |-
      An _operating point_ is a constant input together with the [steady state](/definitions/steady-state) that it holds a system at.
  undergraduate:
    text: |-
      An _operating point_ of $\dot{x} = f(x, u)$ is a pair $(x^{\ast}, u^{\ast})$ of a state and a constant input with $f(x^{\ast}, u^{\ast}) = 0$, around which a system is linearized and designed to operate.
