title: Operating point
term: operating point
applies_to: control systems
synonyms: [trim point (in aerospace)]
levels:
  high-school:
    text: |-
      Consider a system that is held at a steady condition by a constant input.
      An _operating point_ is the constant input together with the [steady state](/definitions/steady-state) that it holds the system at.
  undergraduate:
    text: |-
      Consider a system $\dot{x} = f(x, u)$, which is to be linearized and designed to operate around some state.
      An _operating point_ of the system is a pair $(x^{\ast}, u^{\ast})$ of a state and a constant input with $f(x^{\ast}, u^{\ast}) = 0$.
