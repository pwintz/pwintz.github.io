title: Periodic
term: periodic
applies_to: "functions, signals, and events"
levels:
  elementary:
    text: |-
      Something is _periodic_ if it repeats the same pattern at regular intervals.
  high-school:
    text: |-
      A function $f$ is _periodic_ with period $T > 0$ if $f(t + T) = f(t)$ for all $t$. Periodic events happen at regular intervals of length $T$.
  undergraduate:
    context: dynamical systems
    text: |-
      A solution $x(t)$ is _periodic_ if $x(t + T) = x(t)$ for all $t$ and some $T > 0$.
properties:
  - >-
    If $T$ is a period, so is every positive [integer](/definitions/integer) multiple of $T$.
  - >-
    The trajectory of a nonconstant periodic solution is a closed curve, called a periodic orbit.
