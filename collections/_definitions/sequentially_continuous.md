title: Sequentially continuous function
term: sequentially continuous
applies_to: functions
levels:
  undergraduate:
    text: |-
      Consider a function $f$.
      The function $f$ is _sequentially continuous_ if $x_n \to x$ implies $f(x_n) \to f(x)$ for every convergent [sequence](/definitions/sequence) $(x_n)$ in its domain.
