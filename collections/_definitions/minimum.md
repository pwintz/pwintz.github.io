title: Minimum
term: minimum
applies_to: ordered sets and functions
synonyms: [least element, smallest element, $\min$]
levels:
  elementary:
    text: |-
      Think of a set of numbers, like the temperatures during a week.
      The _minimum_ of the set is the smallest number in it.
    caveat: >-
      Infinite sets might not have a smallest number.
      The set $(0, 1]$ has no smallest element: for any $x$ in it, $x / 2$ is smaller.
  undergraduate:
    text: |-
      Consider an ordered set and a subset $S$ of it.
      The _minimum_ of $S$ is an element of $S$ that is less than or equal to every element of $S$.
      The minimum of a function $f$ is the minimum of its set of values, if it exists.
properties:
  - >-
    A set has at most one minimum.
    If the minimum exists, it equals the [infimum](/definitions/infimum).
