---
title: Cardinal number
term: cardinal number
applies_to: numbers
levels:
  elementary:
    text: |-
      A _cardinal number_ is a number that tells how many.
  graduate:
    context: set theory
    text: |-
      The _cardinal number_ of a set is its [cardinality](/dictionary/definitions/cardinality). Two sets have the same cardinal number if there is a bijection between them.
properties:
  - >-
    The cardinal numbers include the natural numbers and infinite cardinals, such as $\aleph_0$, the [cardinality](/dictionary/definitions/cardinality) of $\nats$.
