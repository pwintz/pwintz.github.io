---
title: Open-loop control
term: open loop
applies_to: control systems
synonyms: [feedforward control (in some texts)]
levels:
  elementary:
    text: |-
      Think of a machine that is trying to reach a goal, like a toaster making toast.
      In _open-loop_ control, the machine acts without checking the result.
  high-school:
    text: |-
      Consider a controller that chooses the input to a system.
      In _open-loop_ control, the controller chooses the input without measuring the result.
  undergraduate:
    text: |-
      Consider a control system $\dot x = f(x, u)$. 
      In _open-loop_ control, the input $u$ is computed in advance, or from the reference alone, and does not depend on measurements of the system's output.
---
