title: Partition of a set
term: partition (of a set)
applies_to: sets
levels:
  elementary:
    text: |-
      Think of a set of things that you sort into groups, like students sorted into classes.
      A _partition_ of the set splits it into groups so that every element is in exactly one group.
  undergraduate:
    text: |-
      Consider a set, and a collection of nonempty, pairwise disjoint [subsets](/dictionary/definitions/subset) of it (called blocks).
      The collection is a _partition_ of the set if the [union](/dictionary/definitions/set-union) of the blocks is the whole set.
      Every element is then in exactly one block.
properties:
  - >-
    Partitions of a set correspond exactly to equivalence [relations](/dictionary/definitions/relation) on it: the blocks are the [equivalence classes](/dictionary/definitions/equivalence-relation).
