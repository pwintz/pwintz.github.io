title: Partition of a set
term: partition (of a set)
applies_to: sets
levels:
  elementary:
    text: |-
      A _partition_ of a set splits it into groups so that every element is in exactly one group.
  undergraduate:
    text: |-
      A _partition_ of a set is a collection of nonempty, pairwise disjoint [subsets](/definitions/subset) (called blocks) whose [union](/definitions/set-union) is the whole set. Every element is in exactly one block.
properties:
  - >-
    Partitions of a set correspond exactly to equivalence [relations](/definitions/relation) on it: the blocks are the equivalence classes.
