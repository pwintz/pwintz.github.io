title: Sparse matrix
term: sparse (matrix)
applies_to: matrices
levels:
  high-school:
    text: |-
      Consider a [matrix](/dictionary/definitions/matrix) and its entries.
      The matrix is _sparse_ if most of its entries are zero.
  undergraduate:
    context: numerical linear algebra
    text: |-
      Consider a large [matrix](/dictionary/definitions/matrix) stored in a computer.
      The matrix is _sparse_ if most of its entries are zero, so that storing and computing with only the nonzero entries saves memory and time.
---
There is no exact threshold.
A [matrix](/dictionary/definitions/matrix) is sparse when it is worth treating it as sparse.
The opposite is a _dense_ matrix, which is unrelated to a [dense](/dictionary/definitions/dense-set) set.
