---
title: Injective function
term: injective
applies_to: functions
synonyms: [injection, one-to-one]
levels:
  # elementary:
  #   text: |-
  #     Think of a function as a machine that sends each input to an output.
  #     The function is _injective_ if no two different inputs give the same output.
  high-school:
    text: |-
      A function $f$ is _injective_ if every two different inputs $x$ and $y$ give different outputs: $f(x) \neq f(y)$.
  undergraduate:
    text: |-
      Consider a function $f : X \to Y$.
      The function $f$ is _injective_ if, for all $x_1, x_2 \in X$,

      $$f(x_1) = f(x_2) \implies x_1 = x_2.$$
---
"One-to-one" (injective) is easily confused with "one-to-one correspondence" ([bijective](/definitions/bijective)).
