title: Injective function
term: injective
applies_to: functions
synonyms: [one-to-one]
levels:
  elementary:
    text: |-
      A function is _injective_ if it never sends two different inputs to the same output.
  high-school:
    text: |-
      A function is _injective_ if different inputs always give different outputs.
  undergraduate:
    text: |-
      A function $f : X \to Y$ is _injective_ if $f(x_1) = f(x_2)$ implies $x_1 = x_2$ for all $x_1, x_2 \in X$.
---
"One-to-one" (injective) is easily confused with "one-to-one correspondence" ([bijective](/definitions/bijective)).
