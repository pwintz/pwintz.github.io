title: Upper semicontinuous set-valued map
term: upper semicontinuous
applies_to: set-valued maps
synonyms: [upper hemicontinuous]
levels:
  graduate:
    context: set-valued analysis (Berge)
    text: |-
      A set-valued map $F : X \rightrightarrows Y$ is _upper semicontinuous_ at $x$ if for every open set $U$ containing $F(x)$, there is a neighborhood $V$ of $x$ with $F(y) \subseteq U$ for all $y \in V$.
