title: Finite set
term: finite
applies_to: sets
levels:
  elementary:
    text: |-
      Think of a set of things, and try to count them.
      The set is _finite_ if you could count its elements completely, finishing at some number.
  undergraduate:
    text: |-
      Consider a set $S$.
      The set $S$ is _finite_ if $S$ is empty or in bijection with $\lbrace 1, 2, \dots, n \rbrace$ for some $n \in \mathbb{N}$.
---
For a number, "finite" means "a [real number](/definitions/real-number), not $\pm \infty$," which is unrelated.
