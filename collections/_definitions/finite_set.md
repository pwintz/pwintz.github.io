published: false
title: Finite set
term: finite
applies_to: sets
levels:
  elementary:
    text: |-
      A set is _finite_ if you could count its elements completely, finishing at some number.
  undergraduate:
    text: |-
      A set is _finite_ if it is empty or in bijection with $\lbrace 1, 2, \dots, n \rbrace$ for some $n \in \mathbb{N}$.
---
For a number, "finite" means "a [real number](/definitions/real-number), not $\pm \infty$," which is unrelated.
