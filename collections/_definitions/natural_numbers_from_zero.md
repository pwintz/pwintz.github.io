title: Natural numbers (starting at 0)
term: natural numbers (from 0)
applies_to: numbers
synonyms: [nonnegative integers]
levels:
  elementary:
    text: |-
      The _natural numbers_ are the numbers $0, 1, 2, 3, \dots$ that answer "how many?"
  undergraduate:
    text: |-
      The _natural numbers_ are the set $\lbrace 0, 1, 2, 3, \dots \rbrace$ of nonnegative [integers](/definitions/integer), often written $\mathbb{N}$, $$\mathbb{N}_0$$, or $$\mathbb{Z}_{\geq 0}$$.
  graduate:
    context: set theory
    text: |-
      The _natural numbers_ are the smallest set that contains $0 = \emptyset$ and contains $n \cup \lbrace n \rbrace$ whenever it contains $n$ (the von Neumann construction). Each natural number is the set of all smaller natural numbers.
---
This convention is common in set theory, logic, and computer science, and is the one used by the ISO 80000-2 standard. Compare [natural numbers starting at 1](/definitions/natural-numbers-from-one).
