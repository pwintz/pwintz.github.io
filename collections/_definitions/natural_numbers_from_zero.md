---
title: Natural numbers (starting at 0)
term: natural numbers (from 0)
applies_to: numbers
synonyms: ["nonnegative integers", "$\\nats$", "$\\nats_0$", "$\\mathbb{Z}_{\\geq 0}$"]
levels:
  elementary:
    text: |-
      The _natural numbers_ are the numbers $0, 1, 2, 3, \dots$ that can be used to answer questions about "how many?" objects there are.
  undergraduate:
    text: |-
      The _natural numbers_ are the set $\setdef{0, 1, 2, 3, \dots}$ of nonnegative [integers](/dictionary/definitions/integer), often written $\nats$, $$\nats_0$$, or $$\mathbb{Z}_{\geq 0}$$.
  graduate:
    context: set theory
    text: |-
      The _natural numbers_ are the smallest set that contains $0 = \emptyset$ and contains $n \cup \setdef{n}$ whenever it contains $n$ (the von [Neumann](/dictionary/definitions/neumann-condition) construction).
      Each natural number is the set of all smaller natural numbers.
---
This convention is common in set theory, logic, and computer science, and is the one used by the ISO 80000-2 standard.
Compare [natural numbers starting at 1](/dictionary/definitions/natural-numbers-from-one).
