title: Uniform
term: uniform
applies_to: properties that depend on a parameter
levels:
  high-school:
    text: |-
      A property holds _uniformly_ if the same constants work for every value of a parameter at once, rather than needing different constants for different values.
  undergraduate:
    text: |-
      A property holds _uniformly_ (in a parameter) if the same constants work for every value of the parameter.
---
A uniform distribution, in which all outcomes are equally likely, is a different use of the word.
