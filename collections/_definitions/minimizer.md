title: Minimizer
term: minimizer
applies_to: functions
synonyms: [argument of the minimum, "$\\operatorname{arg\\hspace{1mu}min}$"]
levels:
  high-school:
    text: |-
      A _minimizer_ of a function is an input at which the function takes its smallest value.
  undergraduate:
    text: |-
      A _minimizer_ of $f$ is a point $x^{\ast}$ in the domain of $f$ with $f(x^{\ast}) \leq f(x)$ for all $x$ in the domain. The set of all minimizers is $\operatorname{arg\hspace{1mu}min} f$. The minimizer is an input; the minimum $f(x^{\ast})$ is an output.
