title: Linearly independent vectors
term: linearly independent
applies_to: sets of vectors
levels:
  high-school:
    text: |-
      Consider a list of [vectors](/definitions/vector) $v_1, \dots, v_k$.
      The vectors are _linearly independent_ if none of them can be built from the others by stretching and adding.
  undergraduate:
    text: |-
      Consider vectors $v_1, \dots, v_k$ in a vector space.
      The vectors are _linearly independent_ if the only solution of

      $$c_1 v_1 + \dots + c_k v_k = 0$$

      is $c_1 = \dots = c_k = 0$.
properties:
  - >-
    A set that contains the [zero vector](/definitions/zero-vector) is not linearly independent, because $1 \cdot 0 = 0$.
