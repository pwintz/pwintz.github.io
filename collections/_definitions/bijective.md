title: Bijective function
term: bijective
applies_to: functions
synonyms: [bijection, one-to-one correspondence, invertible function]
levels:
  elementary:
    text: |-
      Think of a function as a machine that sends each input to an output.
      The function is _bijective_ if it pairs things up perfectly: every possible output is used by exactly one input.
  high-school:
    text: |-
      Consider a function and its [codomain](/definitions/codomain).
      The function is _bijective_ if it is both [injective](/definitions/injective) and [surjective](/definitions/surjective): each element of the codomain is the output of exactly one input.
  undergraduate:
    text: |-
      Consider a function $f : X \to Y$.
      The function $f$ is _bijective_ if $f$ is [injective](/definitions/injective) and [surjective](/definitions/surjective).
properties:
  - >-
    A function $f : X \to Y$ is bijective if and only if it has an inverse function $f^{-1} : Y \to X$.
  - >-
    A composition of bijections is a bijection.
