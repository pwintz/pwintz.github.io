---
title: Class-K function
term: "class-$\\mathcal{K}$"
applies_to: scalar functions
levels:
  graduate:
    context: nonlinear control
    text: |-
      Consider a function $\alpha : [0, a) \to [0, \infty)$.
      The function $\alpha$ is of *class-$\mathcal{K}$* if 
      
      1. $\alpha$ is [continuous](/dictionary/definitions/continuous)
      2. $\alpha$ is strictly increasing and 
      3. $\alpha(0) = 0$.
