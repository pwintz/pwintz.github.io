title: Class-K function
term: "class-$\\mathcal{K}$"
applies_to: scalar functions
levels:
  graduate:
    context: nonlinear control
    text: |-
      Consider a function $\alpha : [0, a) \to [0, \infty)$.
      The function $\alpha$ is of *class-$\mathcal{K}$* if $\alpha$ is [continuous](/definitions/continuous) and strictly increasing and $\alpha(0) = 0$.
