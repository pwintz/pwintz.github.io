---
title: Cardinality
term: cardinality
applies_to: sets
synonyms: [$\lvert A \rvert$, "$\\#A$"]
levels:
  elementary:
    text: |-
      The _cardinality_ of a set is how many elements it has.
    caveat: >-
      For infinite sets, "how many" needs a new idea: two sets have the same cardinality if their elements can be paired up one-to-one.
  high-school:
    text: |-
      The _cardinality_ of a finite set is its number of elements.
  graduate:
    context: set theory
    text: |-
      Sets $A$ and $B$ have the same _cardinality_ if there is a bijection between them. This extends counting to infinite sets.
properties:
  - >-
    Infinite sets can have different cardinalities: $\lvert \mathbb{N} \rvert < \lvert \reals \rvert$.
  - >-
    Every set has smaller cardinality than its power set (Cantor's theorem).
---
