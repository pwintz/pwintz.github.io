title: Unforced system
term: unforced
applies_to: dynamical systems
synonyms: [free, homogeneous (for linear systems)]
levels:
  high-school:
    text: |-
      A system is _unforced_ if nothing outside pushes on it (it has no input or forcing).
  undergraduate:
    text: |-
      A system is _unforced_ if it has no input and no forcing term, or if its input is set to zero, as in $\dot{x} = f(t, x, 0)$. Its response is the zero-input (or free) response.
