title: Input strictly passive system
term: input strictly passive
applies_to: input-output systems
levels:
  graduate:
    context: nonlinear control
    text: |-
      A system is _input strictly passive_ if $u^{\top} y \geq \dot{V} + u^{\top} \varphi(u)$ for some function $\varphi$ with $u^{\top} \varphi(u) > 0$ for all $u \neq 0$. If only $u^{\top} y \geq \dot{V} + u^{\top} \varphi(u)$ holds, without the sign condition, the system is _input-feedforward passive_.
