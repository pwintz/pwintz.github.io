---
title: Open map
term: open map
applies_to: functions
levels:
  undergraduate:
    text: |-
      A function $f : \reals^n \to \reals^m$ is called _open_ if the image of every [open set](/definitions/open-set) $U$ in $\reals^n$ is an open set $f(U)$ in $\reals^m$.
  graduate:
    text: |-
      Consider topological spaces $S$ and $T$.
      A function $f : S\to T$ is called _open_ if the image of every [open set](/definitions/open-set) $U$ in $S$ is an open set $f(U)$ in $T$.
---
