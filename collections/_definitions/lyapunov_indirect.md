title: "Lyapunov's indirect method"
term: Lyapunov (indirect)
applies_to: nonlinear systems
synonyms: [linearization, "Lyapunov's first method"]
levels:
  high-school:
    text: |-
      _Lyapunov's indirect method_ decides whether an [equilibrium](/definitions/equilibrium) is stable by approximating the system near it with a linear system and checking the linear one.
  undergraduate:
    context: nonlinear systems
    text: |-
      _Lyapunov's indirect method_ linearizes the system at the [equilibrium](/definitions/equilibrium). If every [eigenvalue](/definitions/eigenvalue) of the [Jacobian](/definitions/jacobian) has negative real part, the equilibrium is (locally) [exponentially stable](/definitions/exponentially-stable). If some eigenvalue has positive real part, it is unstable. If neither holds, the test is inconclusive.
