---
title: Topological Space
term: topological space
applies_to: sets
levels:
  high-school:
    text: |-
      A _topological space_ is a set $X$ together with a [topology](/dictionary/definitions/topology) on $X$. 
      The topology defines which [subsets](/dictionary/definitions/subset) are considered "open."
  undergraduate:
    text: |-
      A _topological space_ is a pair $(X, \mathcal{T})$, where $X$ is a set and $\mathcal{T}$ is a [topology](/dictionary/definitions/topology) on $X$.
      The sets in $\mathcal{T}$ are called the [open sets](/dictionary/definitions/open-set) of $(X, \mathcal{T})$.
properties:
  # TODO: Does this method of defining a topology on metric spaces have a name?
  - |-
    Every [metric space](/dictionary/definitions/metric-space) is a topological space, whose open sets are the [unions](/dictionary/definitions/set-union) of [open balls](/dictionary/definitions/open-ball).
  # - |-
  #   One set can have several topologies, so one set can be the underlying set of several different topological spaces.
---
When the topology is clear from context, a topological space $(X, \mathcal{T})$ is often written as just $X$.
