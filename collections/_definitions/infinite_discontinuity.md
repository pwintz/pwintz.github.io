title: Infinite discontinuity
term: infinite discontinuity
applies_to: functions
levels:
  high-school:
    text: |-
      Consider a function $f$ and a point $a$.
      The function $f$ has an _infinite discontinuity_ at $a$ if the graph of $f$ shoots up or down without bound as $x$ approaches $a$ from at least one side, so the graph has a vertical asymptote at $x = a$.
  undergraduate:
    text: |-
      Consider a function $f$ defined near a point $a$.
      The function $f$ has an _infinite discontinuity_ at $a$ if

      $$\lim_{x \to a^{-}} \abs{f(x)} = \infty \quad \text{or} \quad \lim_{x \to a^{+}} \abs{f(x)} = \infty.$$
