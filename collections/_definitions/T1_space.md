term: T₁
applies_to: topological spaces
synonyms: [Fréchet space (in some texts), accessible space]
levels:
  graduate:
    context: topology
    text: |-
      A topological space is _T₁_ if every single point is a closed set.
properties:
  - >-
    A space is T₁ if and only if, for any two distinct points, each has a neighborhood that does not contain the other.
