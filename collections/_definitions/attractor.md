title: Attractor
term: attractor
applies_to: dynamical systems
levels:
  high-school:
    text: |-
      An _attractor_ is a set of states that a system settles into over time from nearby starting states, such as a resting point or a repeating cycle.
  graduate:
    text: |-
      An _attractor_ is a [compact](/definitions/compact), invariant set $A$ that is [attractive](/definitions/attractive): every solution starting near $A$ converges to $A$.
---
Definitions vary. Some also require an attractor to be stable, or to contain no smaller attractor, or only require convergence for a set of initial states with positive measure (Milnor attractors).
