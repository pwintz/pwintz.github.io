title: Countably infinite set
term: countably infinite
applies_to: sets
synonyms: [denumerable]
levels:
  high-school:
    text: |-
      A set is _countably infinite_ if its elements can be listed in an infinite [sequence](/definitions/sequence) $a_1, a_2, a_3, \dots$ that eventually reaches every element.
  undergraduate:
    text: |-
      A set is _countably infinite_ if it is in bijection with $\mathbb{N}$, so its elements can be listed as $a_1, a_2, a_3, \dots$ without missing any.
properties:
  - >-
    $\mathbb{N}$, $\mathbb{Z}$, and $\mathbb{Q}$ are countably infinite, but $\reals$ is not.
  - >-
    Every infinite [subset](/definitions/subset) of a countably infinite set is countably infinite, and a countable [union](/definitions/set-union) of countable sets is countable (assuming the axiom of countable choice).
---
"Countable" is ambiguous: some authors mean countably infinite, and others mean finite or countably infinite.
