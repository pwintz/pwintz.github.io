title: Ordinal number
term: ordinal number
applies_to: numbers
levels:
  elementary:
    text: |-
      An _ordinal number_ is a number that tells position in an order.
  graduate:
    context: set theory
    text: |-
      An _ordinal number_ is the order type of a well-ordered set. The finite ordinals are the natural numbers, followed by infinite ordinals $\omega, \omega + 1, \omega + 2, \dots$
properties:
  - >-
    For infinite sets, ordinals and cardinals differ: $\omega$ and $\omega + 1$ are different ordinals, but the corresponding sets have the same [cardinality](/definitions/cardinality), $\aleph_0$.
