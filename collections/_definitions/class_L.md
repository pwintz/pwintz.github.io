title: Class-L function
term: "class-$\\mathcal{L}$"
applies_to: scalar functions
levels:
  graduate:
    context: nonlinear control
    text: |-
      Consider a [continuous](/definitions/continuous) function $\sigma : [0, \infty) \to [0, \infty)$.
      The function $\sigma$ is of *class-$\mathcal{L}$* if $\sigma$ is nonincreasing and $\sigma(s) \to 0$ as $s \to \infty$.
      Some authors require it to be strictly decreasing.
