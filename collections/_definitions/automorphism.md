title: Automorphism
term: automorphism
applies_to: structure-preserving maps
levels:
  high-school:
    text: |-
      Consider an object with some structure, such as a square or a number system.
      An _automorphism_ is a way of matching the object with itself that preserves its structure.
  undergraduate:
    context: abstract algebra
    text: |-
      Consider an algebraic object, such as a group or a vector space.
      An _automorphism_ of the object is an isomorphism from the object to itself: a [bijective](/definitions/bijective) [endomorphism](/definitions/endomorphism) whose inverse is also structure preserving.
