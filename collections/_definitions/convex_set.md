title: Convex set
term: convex set
applies_to: subsets of a vector space
levels:
  high-school:
    text: |-
      Consider a set $C$ of points in the plane or in space.
      The set $C$ is _convex_ if, for every two points of $C$, the straight segment between them lies in $C$.
  undergraduate:
    text: |-
      Consider a set $C$ in a real vector space.
      The set $C$ is _convex_ if, for all $x, y \in C$ and every $\lambda \in [0, 1]$,

      $$\lambda x + (1 - \lambda) y \in C.$$
properties:
  - >-
    Every [intersection](/dictionary/definitions/set-intersection) of convex sets is convex, but a [union](/dictionary/definitions/set-union) of convex sets need not be.
