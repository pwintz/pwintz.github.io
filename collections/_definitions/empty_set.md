title: Empty set
term: empty set
applies_to: sets
synonyms: ['$\emptyset$', '$\setdef{}$']
levels:
  elementary:
    text: |-
      Think of a set as a box that holds things.
      The _empty set_ is the set with nothing in it.
  high-school:
    text: |-
      The _empty set_ is the set with no elements, written $\emptyset$ or $\setdef{}$.
---
The empty set is not the number $0$, and it is not the same as $\setdef{\emptyset}$, which has one element.
