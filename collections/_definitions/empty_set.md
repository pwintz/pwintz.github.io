title: Empty set
term: empty set
applies_to: sets
synonyms: [$\emptyset$, $\lbrace \rbrace$]
levels:
  elementary:
    text: |-
      The _empty set_ is the set with nothing in it.
  high-school:
    text: |-
      The _empty set_ is the set with no elements, written $\emptyset$ or $\lbrace \rbrace$.
---
The empty set is not the number $0$, and it is not the same as $\lbrace \emptyset \rbrace$, which has one element.
