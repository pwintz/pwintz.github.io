title: Element of
term: element of
applies_to: an object and a set
synonyms: [member of, $\in$]
levels:
  elementary:
    text: |-
      $x \in A$ means that $x$ is an _element of_ $A$: one of the things in the set $A$.
  graduate:
    context: axiomatic set theory
    text: |-
      _Element of_, written $\in$, is the primitive [relation](/definitions/relation) of set theory. All other set-theoretic notions are defined in terms of it.
