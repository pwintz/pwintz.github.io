title: Fixed point
term: fixed point
applies_to: functions
levels:
  elementary:
    text: |-
      A _fixed point_ of a function is an input that the function leaves unchanged.
  high-school:
    text: |-
      A _fixed point_ of a function $f$ is a point $x$ with $f(x) = x$: the function leaves it unchanged.
