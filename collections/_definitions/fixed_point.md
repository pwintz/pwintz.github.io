---
title: Fixed point
term: fixed point
applies_to: functions
levels:
  elementary:
    text: |-
      Think of a function as a machine that changes its input into an output.
      A _fixed point_ of the function is an input that the function leaves unchanged: The output equals the input.
  high-school:
    text: |-
      Consider a function $f$ whose inputs and outputs are the same kind of thing.
      A _fixed point_ of $f$ is a point $x$ with $f(x) = x$: the function leaves it unchanged.
  undergraduate:
    text: |-
      Consider a function $f : X \to X$.
      A _fixed point_ of $f$ is a point $x \in X$ such that $f(x) = x$.
---
