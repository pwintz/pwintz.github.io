title: Predicate
term: predicate
applies_to: statements with variables
levels:
  high-school:
    text: |-
      A _predicate_ is a statement with a variable in it, which becomes true or false once a value is chosen for the variable.
  undergraduate:
    context: logic
    text: |-
      A _predicate_ is a statement with one or more variables, such as $P(x)$, that becomes a [proposition](/definitions/proposition) when values are substituted for the variables. Equivalently, it is a function from a set of possible values to $\lbrace \text{true}, \text{false} \rbrace$.
