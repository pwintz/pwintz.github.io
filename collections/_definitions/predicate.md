title: Predicate
term: predicate
applies_to: statements with variables
levels:
  high-school:
    text: |-
      Consider a statement with a variable in it, such as "$x$ is even."
      The statement is a _predicate_: it becomes true or false once a value is chosen for the variable.
  undergraduate:
    context: logic
    text: |-
      Consider a statement with one or more variables, such as $P(x)$.
      The statement is a _predicate_ if it becomes a [proposition](/definitions/proposition) when values are substituted for the variables.
      Equivalently, a predicate is a function from a set of possible values to $\lbrace \text{true}, \text{false} \rbrace$.
