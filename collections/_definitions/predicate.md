---
title: Predicate
term: predicate
applies_to: statements with variables
levels:
  high-school:
    text: |-
      Consider a true/false statement with a variable in it, such as "$x$ is even."
      The statement is a _predicate_: it becomes true or false once a value is chosen for the variable.
  undergraduate:
    context: logic
    text: |-
      Consider a set $X$ of objects.
      A _predicate_ on $X$ is a function $P$ that assigns to each $x \in X$ a [proposition](/dictionary/definitions/proposition) $P(x)$; for example, the predicate "$x$ is prime" assigns to $7$ the proposition "$7$ is prime."
      Each proposition is either true or false, so the predicate $P$ determines the function

      $$P : X \to \setdef{\text{true}, \text{false}}$$

      that sends each $x$ to the truth value of $P(x)$. 
      Logic books usually identify the predicate with this function.
---
In grammar, the _predicate_ of a sentence is the part that says something about the subject: in "$7$ is prime," the subject is "$7$" and the predicate is "is prime."
Logic borrowed the word: the logical predicate "$x$ is prime" is the grammatical predicate with a variable in place of the subject.
Let $P(x)$ be the predicate $x \text{ is prime}$. 
Then, the statement "$7$ is prime" is $P(7)$.
