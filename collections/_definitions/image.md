title: Image
term: image
applies_to: functions and sets
levels:
  elementary:
    text: |-
      Think of a function as a machine that turns inputs into outputs.
      The _image_ of the function is the set of all of the outputs that it actually gives.
  high-school:
    text: |-
      Consider a function and all of the inputs in its domain.
      The _image_ of the function is the set of all of its outputs.
  undergraduate:
    text: |-
      Consider a function $f : X \to Y$ and a set $A \subseteq X$.
      The _image_ of $A$ is $f(A) = \lbrace f(x) : x \in A \rbrace$.
      The image of $f$ is $f(X)$.
