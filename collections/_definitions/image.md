term: image
applies_to: functions and sets
levels:
  elementary:
    text: |-
      The _image_ of a function is the set of all of the outputs that it actually gives.
  high-school:
    text: |-
      The _image_ of a function is the set of all of its outputs.
  undergraduate:
    text: |-
      For $f : X \to Y$ and $A \subseteq X$, the _image_ of $A$ is $f(A) = \lbrace f(x) : x \in A \rbrace$. The image of $f$ is $f(X)$.
