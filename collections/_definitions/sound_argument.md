title: Sound Argument
term: sound (argument)
applies_to: arguments
levels:
  high-school:
    text: |-
      An [argument](/dictionary/definitions/argument-logic) is _sound_ if the argument is [valid](/dictionary/definitions/valid-argument) and all of its [premises](/dictionary/definitions/premise) are true.
      For example, "All humans are mortal; Socrates is human; therefore, Socrates is mortal" is sound, but "All cats can fly; Tom is a cat; therefore, Tom can fly" is not sound, because cats cannot fly.
  undergraduate:
    context: logic
    text: |-
      Consider an [argument](/dictionary/definitions/argument-logic) $p_1, \dots, p_n \;\therefore\; q$.
      The argument is _sound_ if

      1. the argument is [valid](/dictionary/definitions/valid-argument), and
      2. each [premise](/dictionary/definitions/premise) $p_1, \dots, p_n$ is true.
properties:
  - >-
    The [conclusion](/dictionary/definitions/conclusion) of a sound [argument](/dictionary/definitions/argument-logic) is true.
---
In mathematical logic, a proof system is also called _sound_ if every formula that the proof system proves is valid, which is a different meaning.
