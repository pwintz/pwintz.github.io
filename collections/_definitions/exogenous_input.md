title: Exogenous input
term: exogenous input
applies_to: control systems
synonyms: [external input]
levels:
  high-school:
    text: |-
      Consider a system that changes over time.
      An _exogenous input_ is any signal that comes into the system from outside it, such as a [control input](/dictionary/definitions/control-input) or a [disturbance](/dictionary/definitions/disturbance).
  undergraduate:
    context: control systems
    text: |-
      Consider a control system.
      An _exogenous input_ is any signal that enters the system from outside, rather than being determined by the system's own state.
      This includes [control inputs](/dictionary/definitions/control-input), reference signals, [disturbances](/dictionary/definitions/disturbance), and noise.
---
In robust control (for example, in $H_{\infty}$ problems), "exogenous input" often means only the inputs that the controller does _not_ choose, such as references, [disturbances](/dictionary/definitions/disturbance), and noise, as opposed to the [control input](/dictionary/definitions/control-input) $u$.
