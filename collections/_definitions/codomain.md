title: Codomain of a function
term: codomain
applies_to: functions
synonyms: [target]
levels:
  high-school:
    text: |-
      Consider a function.
      The _codomain_ of the function is the set of values that its outputs are allowed to be.
      It can be larger than the set of outputs that actually occur: for $f(x) = x^2$ with real outputs, the codomain is all [real numbers](/dictionary/definitions/real-number), but only nonnegative numbers occur.
  undergraduate:
    text: |-
      Consider a function $f : X \to Y$.
      The _codomain_ of $f$ is the set $Y$.
      Every output is in $Y$, but not every element of $Y$ needs to be an output.
---
The codomain is part of the definition of a function.
For example, $x \mapsto x^2$ as a function $\reals \to \reals$ is not [surjective](/dictionary/definitions/surjective), but as a function $\reals \to [0, \infty)$ it is.
