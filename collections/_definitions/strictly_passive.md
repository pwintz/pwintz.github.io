levels:
  context: nonlinear control
  undergraduate: # TODO: Check if this is precise.
    An input-output system is called _strictly passive_ if some of the energy coming into the system is dissipated whenever the state is not at the origin.
  graduate:
    context: nonlinear control
    text: |-
      A system is _strictly passive_ if $u^{\top} y \geq \dot{V} + \psi(x)$ for some [positive definite](/definitions/positive-definite-function) function $\psi$ of the state.
