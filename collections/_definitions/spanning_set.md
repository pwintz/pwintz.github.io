---
title: Spanning Set
term: spanning set
applies_to: sets of vectors
synonyms: [generating set]
levels:
  high-school:
    text: |-
      Consider a space of [vectors](/dictionary/definitions/vector), such as the plane, in which vectors can be added and stretched.
      A _spanning set_ of the space is a set of vectors from which every vector in the space can be built by stretching each of them and adding the results.
      That is, $\vect{v}_1$, $\vect{v}_2$, ..., $\vect{v}_n$ is a spanning set of $V$ if every vector in $V$ is a [linear combination](/dictionary/definitions/linear-combination) of $\vect{v}_1$, $\vect{v}_2$, ..., $\vect{v}_n$.
  undergraduate:
    text: |-
      Consider a [vector space](/dictionary/definitions/vector-space) $V$.
      A _spanning set_ of $V$ is a set of vectors $\vect{v}_1, \dots, \vect{v}_k$ in $V$ such that the [span](/dictionary/definitions/span) of $\vect{v}_1, \dots, \vect{v}_k$ is $V$:

      $$\Span{\vect{v}_1, \dots, \vect{v}_k} = V.$$
properties:
  - |-
    Every spanning set of $V$ contains a [basis](/dictionary/definitions/vector-basis) of $V$.
  - |-
    A spanning set of an $n$-dimensional space has at least $n$ vectors.
---
