title: Spanning set
term: spanning set
applies_to: sets of vectors
synonyms: [generating set]
levels:
  high-school:
    text: |-
      Consider a space of [vectors](/definitions/vector), such as the plane, in which vectors can be added and stretched.
      A _spanning set_ of the space is a set of vectors from which every vector in the space can be built by stretching each of them and adding the results.
  undergraduate:
    text: |-
      Consider a [vector space](/definitions/vector-space) $V$.
      A _spanning set_ of $V$ is a set of vectors $v_1, \dots, v_k$ in $V$ such that the [span](/definitions/span) of $v_1, \dots, v_k$ is $V$:

      $$\operatorname{span}(v_1, \dots, v_k) = V.$$
properties:
  - >-
    Every spanning set of $V$ contains a [basis](/definitions/vector-basis) of $V$.
  - >-
    A spanning set of an $n$-dimensional space has at least $n$ vectors.
