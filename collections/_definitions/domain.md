title: Domain of a function
term: domain
applies_to: functions
levels:
  elementary:
    text: |-
      Think of a function as a machine that takes inputs and gives outputs.
      The _domain_ of the function is the set of inputs that it accepts.
      If a function machine only accepts [whole numbers](/definitions/whole-numbers), its domain is the whole numbers.
  high-school:
    text: |-
      Consider a function given by a rule, such as a formula.
      The _domain_ of the function is the set of inputs for which it is defined.
    caveat: >-
      In high school, the domain is usually found as the largest set on which a formula makes sense.
      At higher levels, the domain is chosen as part of defining the function, and can be smaller.
  undergraduate:
    text: |-
      Consider a function $f : X \to Y$.
      The _domain_ of $f$ is the set $X$.
