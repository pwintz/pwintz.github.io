title: Domain of a function
term: domain
applies_to: functions
levels:
  elementary:
    text: |-
      The _domain_ of a function is the set of inputs that it accepts. If a function machine only accepts [whole numbers](/definitions/whole-numbers), its domain is the whole numbers.
  high-school:
    text: |-
      The _domain_ of a function is the set of inputs for which it is defined.
    caveat: >-
      In high school, the domain is usually found as the largest set on which a formula makes sense. At higher levels, the domain is chosen as part of defining the function, and can be smaller.
  undergraduate:
    text: |-
      The _domain_ of a function $f : X \to Y$ is the set $X$.
