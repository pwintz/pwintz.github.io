---
title: Domain of a Function
term: domain
applies_to: functions
levels:
  elementary:
    text: |-
      Think of a function as a machine that takes inputs and gives outputs.
      The _domain_ of the function is the set of inputs that it accepts.
    # If a function machine only accepts [whole numbers](/dictionary/definitions/whole-numbers), then its domain is the whole numbers.
  high-school:
    text: |-
      Consider a function $f$ given by a rule, such as a formula.
      The _domain_ of $f$ is the set of inputs $x$ for which $f(x)$ is defined.
    caveat: >-
      In high school, the domain is usually found as the largest set on which a formula makes sense.
      At higher levels, the domain is chosen as part of the definition of the function, and can be smaller than the set where the formula makes sense.
  undergraduate:
    text: |-
      Consider a function $f : X \to Y$.
      The _domain_ of $f$ is the set $X$.
---
