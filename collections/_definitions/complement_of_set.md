published: false
title: Complement of a Set
term: complement
applies_to: sets
levels:
  high-school:
    context: a set $X$
    text: |-
      Consider a set $A$ whose elements are all in $X$.
      The _complement_ of $A$ is the set of elements of $X$ that are not in $A$.
  undergraduate:
    context: a set $X$
    text: |-
      Consider a [subset](/dictionary/definitions/subset) $A \subseteq X$.
      The _complement_ of $A$ is

      $$A^c = X \setdiff A = \setdef{x \in X \suchthat x \notin A}.$$
---
The complement of $A$ depends on the set $X$ that contains $A$.
Some texts write the complement as $\overline{A}$ or $A^\prime$, which can be confused with the closure and the derived set of $A$.
For $\reals$ with the cofinite [topology](/dictionary/definitions/topology), the complement of a set $A \subseteq \reals$ is $\reals \setdiff A$.
