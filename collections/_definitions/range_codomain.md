title: Range (codomain)
term: range (codomain)
applies_to: functions
levels:
  high-school:
    text: |-
      Consider a function, and the set of values that its outputs are allowed to be (its [codomain](/definitions/codomain)).
      In some texts, the _range_ of the function is that set, rather than the outputs that actually occur.
  undergraduate:
    text: |-
      Consider a function $f : X \to Y$.
      In some texts, especially older ones, the _range_ of $f$ is the set $Y$, its [codomain](/definitions/codomain).
---
