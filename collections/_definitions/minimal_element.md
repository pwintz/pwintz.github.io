title: Minimal element
term: minimal element
applies_to: partially ordered sets
levels:
  high-school:
    text: |-
      A _minimal element_ of a set is an element with nothing in the set smaller than it. When some pairs cannot be compared, as with sets ordered by "is a [subset](/definitions/subset) of," a set can have several minimal elements.
  undergraduate:
    text: |-
      A _minimal element_ of $S$ is an element $m$ of $S$ such that no element of $S$ is strictly smaller than $m$.
properties:
  - >-
    A set can have several minimal elements, and a minimal element need not be a minimum, because some elements might not be comparable to it.
  - >-
    If a set has a minimum, the minimum is its only minimal element.
  - >-
    In a totally ordered set, such as $\reals$, minimal elements and minima are the same.
