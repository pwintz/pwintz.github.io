title: Function
term: function
applies_to: mappings
synonyms: [map, mapping]
levels:
  elementary:
    text: |-
      A _function_ is a rule that takes an input and gives exactly one output, like a machine.
  high-school:
    text: |-
      Consider two sets, a domain $X$ and a [codomain](/definitions/codomain) $Y$.
      A _function_ $f : X \to Y$ assigns to each element $x$ of $X$ exactly one element $f(x)$ of $Y$.
  graduate:
    context: set theory
    text: |-
      Consider two sets $X$ and $Y$, and their product $X \times Y$.
      A _function_ from $X$ to $Y$ is a [subset](/definitions/subset) $f \subseteq X \times Y$ such that for each $x \in X$ there is exactly one $y \in Y$ such that $(x, y) \in f$.
      In this formalization, a function is identified with its graph (together with its [codomain](/definitions/codomain)).
