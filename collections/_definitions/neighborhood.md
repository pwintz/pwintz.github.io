title: Neighborhood
term: neighborhood
applies_to: points
levels:
  undergraduate:
    context: metric and topological spaces
    text: |-
      Consider a point $x$ in a [metric space](/definitions/metric-space) or topological space.
      A _neighborhood_ of $x$ is a set $N$ that contains an [open set](/definitions/open-set) $U$ with $x \in U$.
properties:
  - >-
    In a [metric space](/definitions/metric-space), $N$ is a neighborhood of $x$ if and only if $N$ contains an [open ball](/definitions/open-ball) $B(x, \varepsilon)$ for some $\varepsilon > 0$.
  - >-
    A set is open if and only if it is a neighborhood of each of its points.
---
Some authors require a neighborhood to be open; others call an [open set](/definitions/open-set) containing $x$ an _open neighborhood_ of $x$.
