title: Stochastic process
term: stochastic process
applies_to: probability
synonyms: [random process]
levels:
  high-school:
    text: |-
      A _stochastic process_ is a quantity that changes randomly over time: at each time, the value of the quantity is random.
  undergraduate:
    context: probability
    text: |-
      A _stochastic process_ is a collection $(X_t)_{t \in T}$ of [random variables](/dictionary/definitions/random-variable) on one [probability space](/dictionary/definitions/probability-space), indexed by a set $T$ of times, such as $\nats$ or $[0, \infty)$.
properties:
  - >-
    For each outcome $\omega$, the function $t \mapsto X_t(\omega)$ is called a _sample path_ of the process.
  - >-
    A stochastic process is in discrete time if $T$ is [countable](/dictionary/definitions/countable), such as $\nats$, and in continuous time if $T$ is an interval, such as $[0, \infty)$.
