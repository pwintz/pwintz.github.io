title: Autonomous system (no input)
term: autonomous (no input)
applies_to: dynamical systems
levels:
  high-school:
    text: |-
      Consider a system whose state changes over time.
      In another convention, the system is _autonomous_ if nothing from outside acts on it: it has no input.
  undergraduate:
    text: |-
      Consider a system $\dot{x} = f(t, x, u)$.
      In another convention, the system is _autonomous_ if it has no input, as in $\dot{x} = f(t, x)$, which may still depend explicitly on time.
---
This convention appears in some control texts.
