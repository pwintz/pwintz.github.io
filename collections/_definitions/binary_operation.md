title: Binary operation
term: binary operation
applies_to: sets
levels:
  elementary:
    text: |-
      A _binary operation_ is a way of combining two numbers to get a number.
  undergraduate:
    text: |-
      A _binary operation_ on a set $S$ is a function $\ast : S \times S \to S$. The output must be in the same set $S$ (the set is "closed" under the operation).
