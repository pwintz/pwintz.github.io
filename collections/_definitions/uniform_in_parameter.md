title: Uniform (in a parameter)
term: uniform (in a parameter)
applies_to: properties that depend on a parameter
levels:
  high-school:
    text: |-
      Consider a property that involves some constants and a parameter that can take many values.
      The property holds _uniformly_ if the same constants work for every value of the parameter at once, rather than needing different constants for different values.
  undergraduate:
    text: |-
      Consider a property that depends on a parameter and is stated with some constants.
      The property holds _uniformly_ (in the parameter) if the same constants work for every value of the parameter.
properties:
  - >-
    [Uniform continuity](/dictionary/definitions/uniformly-continuous), [uniform convergence](/dictionary/definitions/uniform-convergence), and uniform stability are uniform versions of continuity, convergence, and stability: the same $\delta$, $N$, or bounds work at every point or for every initial time.
