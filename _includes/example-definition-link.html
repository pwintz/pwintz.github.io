{% comment %} A link from an example to the definition of what the example is (its "definition" field), for examples that are terms in their own right, such as a Kalman filter. The link is built from the slug, so a link to a definition that does not exist or is unpublished is marked as broken (by _plugins/dictionary_broken_links.rb). Parameters: example: A document from the "examples" collection. full: If true (on the example's page), render "Definition: ". Otherwise (in lists and grids), render a short "(definition)" link. {% endcomment %} {%- assign edl_slug = include.example.definition -%} {%- if edl_slug -%} {%- assign edl_definition = site.definitions | where: "slug", edl_slug | first -%} {%- assign edl_url = edl_slug | downcase | replace: "_", "-" | prepend: "/dictionary/definitions/" -%} {%- if include.full -%} {%- assign edl_name = edl_definition.term | default: edl_definition.title | default: edl_slug | replace: "_", " " -%}

Definition: {{ edl_name | markdownify | remove: '

' | remove: '

' | strip }}

{%- else %} (definition) {%- endif -%} {%- endif -%}
